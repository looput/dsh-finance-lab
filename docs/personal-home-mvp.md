# 个人投资首页 MVP：实现及验收边界

## 已实现

- 默认新增「首页」，导航整理为「我的工作台」「市场研究」「数据与设置」三级业务分组（两级导航）；首页按概览、档案与判断、每周复盘、待确认分区。统一青绿色主题、卡片、表单、状态提示及键盘焦点样式，保留原有行情/资料/持仓等视图。
- 建档：投资目标、期限（月）、风险自评、最大可承受回撤、基准币种偏好；服务端验证，不是投资适当性认证。
- 首页聚合持仓入口、近期资料来源及时间、提醒、待确认变更、结构化观点和周复盘。
- 投资观点包含理由、验证指标（由用户填阈值/观察日期）、证伪条件。变更生成15分钟有效预览；确认后保留旧版本，卡片引用独立原判断快照。
- `import_holdings`、`upsert_holding` 和面板持仓新增/更新先预览；现有资料的 `opinion` 更新也进入确认队列。队列在内存中，重启失效；单次消费、过期清理、提交前检查数据冲突。只有面板HTTP确认入口，没有Agent确认工具。
- `get_weekly_reviews` 收集最新可用行情、在线新闻和关联资料库摘要，按UTC周一分周去重。每条证据标注来源、原始时间（未知为null）、获取时间和缺失。
- `save_weekly_review` 保存Agent报告及有效证据索引；用户选择维持、需修正或资料不足，并填理由。已复核卡片不可覆盖。选择需修正不等于已改观点，仍须另行预览确认。
- 面板任务显式选择目标会话后，使用该会话的客户端作用域提交；不再枚举第一个root agent，也不使用隐式全局send。目标未打开或未绑定时仅复制任务/提示失败，不误投递。
- 原币未实现价格盈亏：(现价−平均成本)×数量。不含费用、税、分红、已实现盈亏及汇兑损益；缺行情不再以成本价冒充行情。不同币种不合并收益/集中度；跨币种再平衡直接拒绝。

## 当前尚未完成，不能对外声称已具备

- **自动每周调度**：本版是用户点击或会话工具主动触发。没有跨会话后台调度、任务重试/取消、无人值守运行；不能保证每周自动生成。按周提醒/计划任务和会话生命周期绑定应作为后续交付。
- **完整引用真实性校验**：服务端检查引用索引有效，但不会判断模型论断是否被证据支持。行情provider未暴露统一数据时间，明确标为缺失；获取时间不是行情时间。资料快照包含摘要而非全文，不把来源存在等同于可信。
- **合并基准币收益**：基准币种只是偏好。尚无可靠汇率时间序列/历史现金流/分红/费用账本，不能计算TWR、IRR或含汇兑总收益。
- **多用户隔离/内置登录/加密**：这是单用户本地插件；并非金融账户系统。
- **文件工具权限隔离**：宿主有文件/命令权限的Agent仍可直接改本地文件，外部Markdown同步仍会采纳文件修改。预览机制是应用流程保护，不是针对拥有文件权限Agent的安全沙箱。
- 用户显式选择会话ID，并不等于宿主导航栏当前高亮会话；提交经既有input.submit接口，尚无可靠的宿主接受回执。选错会话仍需用户更正。

## 接口权限核实与部署

已检查安装依赖 `@deepseek-ai/dsh-host-webserver` 的路由契约：注册回调直接收发HTTP，未提供插件级身份验证。不能把“由宿主托管”解释为“已鉴权”。

本版所有插件API默认只接受本机socket + localhost/loopback Host；拒绝跨站/同站不同origin请求，POST仅接受JSON，正文上限1MB。**这些是访问边界和CSRF缓解，不是用户认证。**

远程部署必须由运维在所有路径（含SSE）前放置认证代理，并配置环境变量 `DSH_FINANCE_TRUSTED_ORIGIN=https://实际域名`；后端端口必须只允许代理访问。该变量仅允许Host/Origin，不能自行验证代理用户，不能只设变量就开放公网。现有原始HTTP客户端也受此边界约束。

个人档案使用原子rename写盘，创建JSON文件0600/目录0700；持仓、投研索引/新正文、分析、提醒、MCP密钥新增写盘也限制权限。已有目录/正文/密钥权限不自动迁移，用户应检查 `stat` 并收紧；磁盘数据仍是明文，备份、日志、宿主会话、模型提供商也可能留存。新增默认数据文件已加入.gitignore，自定义目录需另行设置忽略/备份策略。持仓损坏文件现在拒绝覆盖，不再静默清空。

## 价值指标定义

不采集打开次数、停留时长或交易频率。

- 建档完成率：试点中完成有效档案的人数 / 知情同意参与建档的人数。应用仅展示个人是否完成，不伪造群体分母或上传埋点。
- 连续复盘：本周或上一周起，连续有至少一张人工决定卡的UTC周数；另外展示已复核卡数/生成卡数。未生成卡的周不纳入该卡片比例，不能把它叫留存率。
- 观点复核质量：人工抽样评价是否对照原判断、逐项检查指标、讨论反证和资料缺失、给出可追溯的维持/修正/暂缓理由。引用索引数量不是质量得分。

建议试点按建档 cohort 连续观察4周，人工复核匿名化样本；阈值应在试点开始前约定，而不是根据交易增加事后定义成功。

## 验证

- `npm run build`
- `npm run test:personal`：建档、周边界、并发去重、缺失证据、报告引用、旧版本和决策保护、持仓/观点预览确认、重放/冲突拒绝、文件权限、损坏文件保护、币种和HTTP访问边界。
- `npm run test:offline`：164通过、0失败。新闻回退测试使用确定性 Eastmoney JSONP fixture，并阻止未声明的外网请求；这验证解析与回退逻辑，不代表线上源实时可用。
- `npm run test:regressions`：11组通过，覆盖行情分类、同代码股票/基金隔离、并发确认/写入、资料清空观点、预览后文件修改、外部索引与元数据冲突、写盘失败回滚、回滚失败后的写入阻断、JSON正文形状、周复盘并发去重。
- 尚未完成宿主浏览器端到端验收或真实模型复盘评测。独立 Chromium 渲染检查尝试受环境阻塞：Playwright 浏览器下载连接失败，备用 Chromium 缺少 libnspr4.so；不能把构建成功当作视觉或真实会话验收。
- 资料事务提供普通 I/O 故障下的尽力回滚，回滚失败后阻断继续写入；不提供多文件崩溃原子性、跨进程锁或符号链接安全隔离。

# 投资策略技能

根据不同市场环境制定投资策略：

## 1. 趋势跟踪策略

### 适用场景
- 明确的上涨或下跌趋势
- 成交量持续放大

### 操作要点
```
买入条件：
- 股价突破20日均线
- MACD金叉
- 成交量放大1.5倍以上

卖出条件：
- 股价跌破10日均线
- MACD死叉
- 盈利达15%以上分批止盈
```

## 2. 价值投资策略

### 选股标准
```
- PE < 行业平均
- PB < 3
- ROE > 15%
- 连续三年盈利增长
- 分红率 > 3%
```

### 操作要点
```
- 左侧交易：分批建仓
- 持仓周期：1-3年
- 忽略短期波动
- 关注基本面变化
```

## 3. 波段操作策略

### 适用场景
- 震荡市
- 箱体运行

### 操作要点
```
买入：支撑位附近
卖出：压力位附近
止损：跌破支撑位3%
止盈：到达压力位或收益率8-12%
```

## 4. 事件驱动策略

### 关注事件类型
```
- 业绩公告（季报、年报）
- 政策发布
- 行业重大新闻
- 并购重组
```

### 操作要点
```
- 提前布局预期
- 事件落地即卖出（利好出尽是利空）
- 严格止损
```

## 5. 策略选择指南

| 市场环境 | 推荐策略 | 仓位建议 |
|----------|----------|----------|
| 牛市初期 | 趋势跟踪 | 70-80% |
| 牛市中期 | 价值投资 | 60-70% |
| 震荡市 | 波段操作 | 50-60% |
| 熊市 | 空仓或事件驱动 | 0-30% |

## 6. 输出格式

```
【投资策略建议】

【市场判断】
- 当前阶段：{牛市/熊市/震荡市}
- 主要矛盾：{描述}

【推荐策略】
- 策略名称：{策略名}
- 策略逻辑：{说明}
- 适用周期：{短期/中期/长期}

【标的筛选】
- 选股条件：{条件}
- 推荐关注：{股票列表}

【操作计划】
- 建仓时机：{条件}
- 仓位控制：{比例}
- 止盈设置：{条件}
- 止损设置：{条件}

【风险提示】
- {风险1}
- {风险2}
```

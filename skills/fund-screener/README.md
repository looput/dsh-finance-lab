# Fund Screener（智能选基助手）

基于盈米MCP 插件的 AI 选基技能，帮用户根据条件筛选基金、发现优质基金、排查问题基金，解决"不知道买什么"的问题。

## 能做什么

- **条件筛选推荐**：按类别、收益、规模、费率等多维度筛选，输出带推荐理由的基金列表
- **债基排雷**：查找近期出现跳水、异动的债券基金，标注告警类型和风险等级
- **热门基金推荐**：获取近期热门基金并增强分析，附带业绩和风险对比
- **债基专项筛选**：按券种配置（利率债/信用债/可转债等）和信用评级（AAA/AA+等）精准筛选
- **换手率筛选**：按股票换手率筛选低换手（长期持有型）或高换手基金
- **策略关联查找**：查找重仓某只基金的投顾策略组合

## 与 fund-analyst 的关系

| | fund-screener（本技能） | fund-analyst |
|--|----------------------|-------------|
| 定位 | 选基引擎 | 分析引擎 |
| 解决问题 | "不知道买什么" | "已知基金怎么样" |
| 输入 | 筛选条件 / 投资偏好 | 基金代码 / 名称 |
| 输出 | 推荐列表 + 推荐理由 | 深度分析报告 |
| 典型场景 | "推荐几只好的偏股基金" | "帮我分析 005827" |

两者互补：先用 fund-screener 找到候选基金，再用 fund-analyst 做深度分析。

## 快速启动

### 方式一：多条件筛选（→ 模板一 HTML，含基金卡片网格 + 业绩/风险对比表）

```
帮我筛选近 1 年收益前 20%、最大回撤小于 15%、规模大于 10 亿的偏股混合基金，生成 HTML 推荐报告：每只基金一张卡片展示收益、回撤、夏普和经理信息，附业绩和风险对比表格
```

### 方式二：主题筛选（→ 模板一 HTML，含基金卡片 + 收益对比柱状图）

```
帮我从红利低波方向筛选 5 只基金，生成 HTML 报告：展示基金卡片（含近 1 年收益、股息率、波动率），用柱状图横向对比各阶段业绩，说明每只基金的推荐理由
```

### 方式三：债基排雷（→ 模板二，含告警列表 + 风险标签）

```
帮我排查最近出现净值跳水或大额赎回的债基，生成排雷报告：列出告警基金的异常指标、可能原因和风险等级标签，标注哪些需要立即关注
```

### 方式四：策略关联查找（→ 模板一 HTML，含基金卡片 + 投顾组合关联）

```
有哪些投顾组合重仓了易方达蓝筹精选？帮我生成 HTML 报告展示这些组合的持仓明细、近期业绩，分析机构投顾为什么看好这只基金
```

## 独立运行

- 本目录业务素材自包含，上传到 Coze 时无需额外业务依赖。
- HTML 报告的完整视觉参考（内联 CSS/JS）由同仓库 `../yingmi-skill/references/demo-report.html` 统一维护，生成 HTML 前必须读取该文件。

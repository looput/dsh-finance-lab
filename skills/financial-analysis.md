# 财务分析技能

当你需要进行财务分析时，按照以下步骤进行：

## 0. 数据源说明

行情为公开 HTTP 直连（对照 AkShare 源码端点，非 akshare 运行时）。若工具失败，先调用 `probe_finance_sources`。

## 1. 获取基础数据

首先使用 `get_stock_kline` 获取股票历史K线数据，了解价格走势：

```
- 获取近60日日线数据
- 观察趋势：上涨、下跌、震荡
- 记录关键价位：支撑位、压力位
```

## 2. 计算技术指标

使用 `calculate_technical_indicators` 计算以下指标：

### 趋势指标
- **MA5/MA10/MA20/MA60**：判断短期、中期、长期趋势
  - MA5上穿MA10：金叉，买入信号
  - MA5下穿MA10：死叉，卖出信号
  - 股价在MA60上方：中长期看涨

### 动量指标
- **MACD**：
  - DIF上穿DEA：买入信号
  - MACD柱状图由负转正：多头启动
  - 顶背离（价格新高但MACD未新高）：卖出信号

- **RSI14**：
  - RSI > 70：超买区，可能回调
  - RSI < 30：超卖区，可能反弹
  - RSI 50附近：盘整

- **KDJ**：
  - K线上穿D线（金叉）：买入信号
  - J值 > 100：严重超买
  - J值 < 0：严重超卖

## 3. 综合分析

### 多头信号组合
- 价格 > MA20 > MA60（多头排列）
- MACD金叉且在零轴上方
- RSI在50-70之间
- KDJ金叉

### 空头信号组合
- 价格 < MA20 < MA60（空头排列）
- MACD死叉且在零轴下方
- RSI在30-50之间
- KDJ死叉

## 4. 输出格式

```
【股票分析】{股票名称} ({代码})

【趋势判断】
- 短期趋势：{上涨/下跌/震荡}
- 中期趋势：{上涨/下跌/震荡}
- 长期趋势：{上涨/下跌/震荡}

【技术指标】
- MACD：{金叉/死叉/背离}
- RSI：{超买/超卖/中性}
- KDJ：{金叉/死叉/钝化}

【综合建议】
- 操作建议：{买入/卖出/持有/观望}
- 目标价位：¥{price}
- 止损价位：¥{price}
- 风险提示：{risk_description}
```

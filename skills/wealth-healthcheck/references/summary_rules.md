# 汇总计算规则

| 输出字段 | 计算方式 |
| --- | --- |
| 总资产 | 所有资产子项之和 |
| 总负债 | 所有负债子项之和 |
| 净资产 | 总资产 － 总负债 |
| 总收入（年度） | 所有月收入子项之和 × 12 |
| 总支出（年度） | 所有月支出子项之和 × 12 |
| 年度结余 | 总收入 － 总支出 |
| 流动性资产 | 存款现金 + 支付宝微信 + 股票 + 基金 + 银行理财 |
| 投资性资产 | 股票 + 基金 + 银行理财 + 储蓄险 + 房产投资 |
| 投资性负债 | 房贷余额（投资） |
| 短期负债 | 银行贷款 + 网贷 + 个人借款 + 其他负债（不含房贷、车贷） |
| 月收入合计 | 所有月收入子项之和 |
| 月支出合计 | 所有月支出子项之和 |
| 月结余 | 月收入合计 － 月支出合计 |
| 被动收入 | 租金收入 + 退休金 + 养老金 |

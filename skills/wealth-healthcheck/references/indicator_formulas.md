# 指标计算公式（9 项）

| 指标 | 公式 |
| --- | --- |
| 储蓄率 | （年收入－年支出）÷ 年收入 × 100% |
| 财务自由度 | 年度被动收入 ÷ 年度支出 |
| 资产负债率 | 总负债 ÷ 总资产 × 100% |
| 投资比率 | 投资性资产 ÷ 总资产 × 100% |
| 投资杠杆率 | 投资性负债 ÷ 投资性资产 × 100%（投资性资产为 0 时不计算） |
| 流动比率 | 流动性资产 ÷ 短期负债（短期负债为 0 时不计算，评为优秀） |
| 应急金覆盖月数 | 流动性资产 ÷ 月支出合计 |
| 各项资产负债占比 | 各资产子项 ÷ 总资产 × 100%；各负债子项 ÷ 总负债 × 100% |
| 各项收入支出占比 | 各收入子项 ÷ 月收入合计 × 100%；各支出子项 ÷ 月支出合计 × 100% |

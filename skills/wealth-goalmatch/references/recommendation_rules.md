# 目标推荐规则

## 第一步：评估已有目标

- 已达成：无需调整
- 进行中且达成率 ≥80%：按计划推进
- 进行中且达成率 <80% 或金额可能不足：给调整建议

## 第二步：推荐新目标（按优先级，已有则跳过）

1. 应急金覆盖月数 <3 且无应急金目标 → 应急金（必要型）
2. 有子女且无子女教育金目标 → 子女教育金（必要型）
3. 距退休 ≤15 年且无养老目标 → 养老储备（必要型）
4. 月结余 >0 且资产负债率 <50% → 置业安居（期望型）
5. 储蓄率 >20% → 品质生活/旅行基金（期望型）
6. 以上不满足 → 长期财富增长（梦想型）

## 第三步：可行性

all_goals_monthly_total 与 monthly_surplus 对比，超出时在 feasibility_note 中提示。

## 建议参数

- 应急金：goal_amount = 月支出 × 6
- 子女教育金：参考 30～50 万
- 新目标 monthly_investment 不超过剩余可用结余的 50%

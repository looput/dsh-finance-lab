# 金融研究团队技能（多智能体协作）

当用户需要对某标的、板块或整个持仓做**多角度深度研究**时，用「研究团队」模式拆分并行子任务，最后汇总为一份报告。

## 何时启用
- 明确要求「团队 / 多角度 / 全面分析 / research team」等。
- 单一标的的买卖决策，需要行情、基本面、宏观、风险等多维度佐证。
- 组合体检：需要同时评估多只持仓与整体风险。

## 编排方式（二选一，按环境可用性）
- **首选**：若已安装 `dsh-agent-teams`，用它把下面的角色注册为队员、按依赖调度任务、汇总结果。
- **兜底**：直接用 DSH 原生 `subagent` 工具并行派发下面每个角色为一个子任务；本插件不重复实现调度框架。

角色与任务只描述「做什么、用哪些工具」，具体调度交给上述编排层。

## 角色 → 工具映射
| 角色 | 职责 | 主要工具 |
|------|------|---------|
| 行情/技术面 | 现价、K线、技术指标、走势 | `get_realtime_quote` `get_stock_kline` `get_hk_quote` `get_us_quote` `calculate_technical_indicators` |
| 基本面/财务 | 财务指标、个股档案、估值 | `get_stock_info` `get_financial_indicators` |
| 宏观 | CPI/PPI/PMI/GDP/M2 与利率环境对板块的影响 | `get_macro_china` |
| 基金 | 同类基金排行、可比净值 | `get_fund_rank` `get_fund_quote` |
| 消息面 | 公司/行业最新资讯、事件 | `web_search` `search_symbol` |
| 风险/持仓 | 组合暴露、集中度、盈亏 | `get_portfolio` `analyze_portfolio`（含 `risk`：配置/集中度/HHI） |

## 任务依赖
1. 先并行：行情/技术面、基本面/财务、宏观、消息面（互相独立）。
2. 再执行：风险/持仓（可引用前几项结论评估仓位与集中度）。
3. 最后：captain（当前会话）汇总。

## 汇总报告格式
```
【标的/组合】{名称}
【结论】{买入/增持/持有/减持/回避} · 信心 {高/中/低}
【行情技术面】{趋势、关键位、指标信号}
【基本面】{估值、财务健康、亮点/风险}
【宏观】{CPI/PPI/PMI/GDP/M2 对该板块的方向性影响}
【消息面】{近期事件、催化/利空}
【风险】{集中度 top1/top3、HHI、建议仓位}
【操作建议】{分批/止损/再平衡}
```

## 边界
- 所有数据源为公开 HTTP 直连，可能限流；失败先 `probe_finance_sources`。
- 输出为研究参考，非投资建议；下单、改持仓仅通过 `upsert_holding` / `import_holdings` 写本地文件，真实交易由用户在券商执行。

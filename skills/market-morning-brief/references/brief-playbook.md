# 简报决策引擎

## 一、简报类型识别与工具选择矩阵

### 1.1 类型识别表

收到用户输入后，按下表匹配简报类型，决定后续调用哪组 MCP 工具。


| 用户输入特征                       | 简报类型   | 输出规模        |
| ---------------------------- | ------ | ----------- |
| "市场早报""速报""日报""每日简报"         | 完整市场早报 | 全量（7 个工具）   |
| "今天市场怎么样""大盘怎么样""收盘了吗"       | 行情速览   | 精简（1-2 个工具） |
| "热点""热门话题""大家在关注什么"          | 热点追踪   | 中等（2-3 个工具） |
| "XX 行业""XX 板块""XX 赛道" + 询问语气 | 行业聚焦   | 中等（3-4 个工具） |
| "基金经理""怎么看后市""观点"            | 经理观点汇总 | 中等（1-2 个工具） |
| "投顾""好文章""策略解读""投顾观点"        | 投顾内容精选 | 精简（1 个工具）   |
| 明确指定日期（如"上周五""3月1日"）         | 指定日期简报 | 按内容类型定      |


### 1.2 工具选择矩阵

#### 完整市场早报

按以下顺序调用，分两批并行：

**第一批（并行）**：


| 工具                    | 参数要点                                                                                 | 优先级 |
| --------------------- | ------------------------------------------------------------------------------------ | --- |
| `GetCurrentTime`      | 无参数                                                                                  | 必调  |
| `GetLatestQuotations` | `calDate`: 不传（默认最近交易日）或用户指定日期                                                        | 必调  |
| `SearchHotTopic`      | 不传参数（默认即可）— 接口返回**当前实时热度榜** Top 10，直接展示；`data` 为空时不生成热点板块                            | 必调  |
| `SearchFinancialNews` | `pageSize`: 30-40（需覆盖 3 个分类各 5 条 = 15 条财经新闻 + 5 条今日关注）— 用于「财经新闻」(15 条) + 「今日关注」(5 条) | 必调  |


**第二批（并行，依赖第一批获取时间）**：


| 工具                           | 参数要点                                                 | 优先级 |
| ---------------------------- | ---------------------------------------------------- | --- |
| `searchRealtimeAiAnalysis`   | `pageSize`: 10 — 用于「且慢陪伴总结」板块                        | 必调  |
| `searchInvestAdvisorContent` | `type`: "碎碎念" 或 "文章"；`pageSize`: 10 — 用于「投顾精选」板块(5条) | 必调  |
| `SearchManagerViewpoint`     | `pageSize`: 10                                       | 可选  |


#### 行情速览


| 工具                    | 参数要点                | 优先级 |
| --------------------- | ------------------- | --- |
| `GetLatestQuotations` | 默认参数                | 必调  |
| `SearchFinancialNews` | `pageSize`: 3（仅取头条） | 可选  |


#### 热点追踪


| 工具                         | 参数要点          | 优先级 |
| -------------------------- | ------------- | --- |
| `SearchHotTopic`           | 默认参数          | 必调  |
| `SearchFinancialNews`      | `pageSize`: 5 | 推荐  |
| `searchRealtimeAiAnalysis` | `pageSize`: 5 | 可选  |


#### 行业聚焦简报

所有工具的 `keyword` 参数设为行业关键词（如"半导体""新能源""医药"）：


| 工具                         | 参数要点                          | 优先级 |
| -------------------------- | ----------------------------- | --- |
| `SearchFinancialNews`      | `keyword`: 行业名；`pageSize`: 10 | 必调  |
| `SearchManagerViewpoint`   | `keyword`: 行业名；`pageSize`: 10 | 必调  |
| `searchRealtimeAiAnalysis` | `keyword`: 行业名；`pageSize`: 5  | 推荐  |
| `SearchHotTopic`           | `keyword`: 行业名                | 可选  |


#### 经理观点汇总


| 工具                         | 参数要点              | 优先级 |
| -------------------------- | ----------------- | --- |
| `SearchManagerViewpoint`   | `pageSize`: 10-20 | 必调  |
| `searchRealtimeAiAnalysis` | `pageSize`: 5     | 可选  |


#### 投顾内容精选


| 工具                           | 参数要点                        | 优先级 |
| ---------------------------- | --------------------------- | --- |
| `searchInvestAdvisorContent` | `type`: "文章"；`pageSize`: 10 | 必调  |


### 1.3 日期参数处理


| 场景       | 处理方式                                  |
| -------- | ------------------------------------- |
| 用户说"今天"  | 不传 `calDate`，默认当日                     |
| 用户说"昨天"  | 通过 `GetCurrentTime` 算出昨日，传入 `calDate` |
| 用户说"上周五" | 通过 `GetCurrentTime` 算出日期              |
| 用户说具体日期  | 格式化为 YYYY-MM-DD 传入                    |
| 非交易日     | `GetLatestQuotations` 自动降级到最近交易日      |

## 二、数据整合与提炼规则

工具返回的原始数据需要提炼后才能写入简报，不能原样搬运。

### 2.1 行情数据提炼

数据来源：`GetLatestQuotations`

**必提取字段**：


| 字段     | 提炼规则                                |
| ------ | ----------------------------------- |
| 主要指数涨跌 | 提取上证指数、深证成指、创业板指、科创50 等主要指数的收盘价和涨跌幅 |
| 涨跌停统计  | 涨停/跌停家数                             |
| 北向资金   | 净流入/流出金额                            |
| 市场温度   | 温度值 + 对应的冷热等级描述                     |
| 成交量    | 两市总成交额                              |


**涨跌幅解读规则**：


| 涨跌幅范围         | 解读     |
| ------------- | ------ |
| > +2%         | "大幅上涨" |
| +1% ~ +2%     | "明显上涨" |
| +0.3% ~ +1%   | "小幅上涨" |
| -0.3% ~ +0.3% | "基本持平" |
| -1% ~ -0.3%   | "小幅下跌" |
| -2% ~ -1%     | "明显下跌" |
| < -2%         | "大幅下跌" |


**市场温度解读规则**：


| 温度范围   | 等级  | 描述     |
| ------ | --- | ------ |
| 0-20   | 极冷  | 市场极度低迷 |
| 20-40  | 偏冷  | 市场情绪偏冷 |
| 40-60  | 中性  | 市场情绪中性 |
| 60-80  | 偏热  | 市场情绪偏热 |
| 80-100 | 极热  | 市场极度火热 |


### 2.2 热点排行提炼

数据来源：`SearchHotTopic`

- **不传 `publishedDate`**（默认即可），接口返回的是**当前实时热度排行榜** Top 10
- `time` 字段是文章原始发布时间，**不是上榜时间**；热度是实时的，无需按 `time` 做任何过滤
- 直接按接口返回顺序展示，每条保留：排名序号 + 标题 + 热度标识（`rank_category` 或 🔥）
- 链接字段为接口的 `link`（非 `url`）
- **HTML 输出时标题必须为 `<a href="{{link}}" target="_blank" rel="noopener noreferrer">` 可点击超链接**
- 若某条无 `link`，标题显示为纯文本
- `data` 为空数组时，整块不生成热点排行

### 2.3 财经新闻提炼

数据来源：`SearchFinancialNews`

- **三个子分类，每个子分类各 5 条，共 15 条**
- 调用策略（推荐方案 B，确保每个分类都有足够条数）：
  - 方案 A：一次调用 `pageSize` 设为 30-40，返回后按分类关键词规则分桶，每桶取 Top 5
  - **方案 B（推荐）**：分 3 次并行调用 `SearchFinancialNews`，分别用不同 `keyword`：
    - 调用 1：`keyword`: "国际 贸易 地缘 制裁 关税"，`pageSize`: 5 → 【国际局势】
    - 调用 2：`keyword`: "A股 港股 美股 行情 资金"，`pageSize`: 5 → 【市场动态】
    - 调用 3：`keyword`: "政策 监管 央行 行业 新能源"，`pageSize`: 5 → 【行业政策】
  - 各调用可设 `startDate` 为最近 3 天以确保时效性
- 每条保留：分类标签 + 标题 + 来源 + 发布时间 + url
- **HTML 输出时标题必须为 `<a href="{{url}}" target="_blank">` 可点击超链接**
- **分类标签规则**（按关键词自动判定）：
  - 【国际局势】：含"美国/欧洲/日本/中东/俄/乌/贸易战/关税/地缘/海峡/制裁/全球"等
  - 【市场动态】：含"A股/港股/美股/行情/涨跌/成交/北向/资金/大盘/基金/ETF"等
  - 【行业政策】：含"政策/监管/央行/财政/发改委/工信部/新能源/芯片/医药/行业/半导体"等
  - 未匹配以上类别时默认标注【市场动态】
- 去重：同一事件多篇报道只保留最新一条
- 必须是时效最新的资讯
- **HTML 展示结构**：三个子板块分别用 H4 小标题（如"国际局势"/"市场动态"/"行业政策"），每个下列 5 条
- 若某一分类不足 5 条，有几条展示几条；若整体 0 条则财经新闻板块不生成

### 2.4 投顾精选提炼

数据来源：`searchInvestAdvisorContent`

- 精选 **5** 条最新投顾内容
- 每条保留：标题 + 作者 + 内容类型标签（文章/碎碎念/社区）+ 摘要（50-100 字）+ 发布时间 + url
- **HTML 输出时标题必须为 `<a href="{{url}}" target="_blank">` 可点击超链接**
- 来源优先级：碎碎念(24h) > 文章(3天) > 社区(7天)
- 质量过滤：标题含"测试/占位/无标题"直接跳过；同一作者最多 2 篇
- 必须是时效最新的内容

### 2.5 且慢陪伴总结提炼

数据来源：`searchRealtimeAiAnalysis`

- 从返回的 AI 解读条目中提取 **5-8 个高频关键词**，以标签形式展示
- 提炼 **5 条投资启示**，每条 1-2 句话，必须基于解读原文
- 每条启示标注来源解读标题
- 合并同主题的观点，去重
- 禁止编造启示内容

### 2.6 今日关注提炼

数据来源：`SearchFinancialNews`

- 从财经新闻中筛选 **5** 条当日重要事件
- 每条保留：时间（HH:MM 或日期）+ 事件描述 + 重要性等级（高/中/低）
- 重要性判断：涉及央行/政策/地缘冲突 → 高；行业/板块变动 → 中；一般资讯 → 低
- 仅展示工具返回的事件，严禁自行编造

## 三、且慢陪伴总结生成规则

且慢陪伴总结替代原"AI 投顾点评"板块，基于 `searchRealtimeAiAnalysis` 返回内容生成，是早报的特色板块。

### 3.1 生成框架

```
【关键词标签云】从 AI 解读条目中提取 5-8 个高频关键词
 ↓
【投资启示 ×5】从解读内容中提炼 5 条核心启示
 ↓
【来源标注】每条启示标注来源的解读标题
```

### 3.2 关键词提取规则

- 遍历所有 AI 解读条目的标题和内容
- 统计高频出现的实体词（指数名、行业名、政策名、事件名等）
- 取频次最高的 5-8 个作为标签
- HTML 中以 `.badge` 标签样式展示

### 3.3 投资启示生成规则


| 规则   | 说明                                            |
| ---- | --------------------------------------------- |
| 数量固定 | 必须生成 5 条启示                                    |
| 基于原文 | 每条启示必须可追溯到 `searchRealtimeAiAnalysis` 返回的具体条目 |
| 来源标注 | 每条启示末尾标注来源解读标题，如"— 来源：《xxx》"                  |
| 客观语气 | 使用"数据显示""解读指出"等客观描述，不用"建议""看好"                |
| 篇幅控制 | 每条 1-2 句话，20-60 字                             |
| 禁止预测 | 不做方向性预测                                       |
| 禁止建议 | 不做投资建议                                        |


### 3.3 HTML 结构示例

```html
<div class="card">
  <div class="section-title">且慢陪伴总结</div>
  <div style="display:flex;flex-wrap:wrap;gap:8px;margin-bottom:16px">
    <span class="badge badge-type">关键词A</span>
    <span class="badge badge-type">关键词B</span>
    <!-- ... 5-8 个关键词标签 -->
  </div>
  <div class="insight-list">
    <div class="insight-item">
      <span class="insight-idx">1</span>
      <div class="insight-content">
        <p>启示内容...</p>
        <p class="insight-source">— 来源：《解读标题》</p>
      </div>
    </div>
    <!-- ... 共 5 条 -->
  </div>
</div>
```

## 四、错误处理与边界场景

### 4.1 非交易日处理


| 场景      | 处理方式                                                |
| ------- | --------------------------------------------------- |
| 周末生成早报  | `GetLatestQuotations` 返回最近交易日数据，标题标注"数据截至 X月X日（周五）" |
| 节假日生成早报 | 同上，标注实际数据日期                                         |
| 交易日盘中生成 | 标注"以下为截至 XX:XX 的盘中数据"或使用上一交易日收盘数据                   |


### 4.2 数据缺失处理


| 场景                               | 处理方式                           |
| -------------------------------- | ------------------------------ |
| `GetLatestQuotations` 失败         | 跳过行情概览区和温度计，其他模块正常输出           |
| `SearchHotTopic` 返回空             | 热点排行板块整块不生成                    |
| `SearchFinancialNews` 返回空        | 财经新闻和今日关注板块整块不生成               |
| `searchInvestAdvisorContent` 返回空 | 投顾精选板块整块不生成                    |
| `searchRealtimeAiAnalysis` 返回空   | 且慢陪伴总结板块整块不生成                  |
| `SearchManagerViewpoint` 返回空     | 不影响（经理观点为可选）                   |
| 全部工具失败                           | 输出错误提示"数据源暂时不可用，请稍后重试"，不输出空白简报 |


### 4.3 数据质量处理


| 场景             | 处理方式                                  |
| -------------- | ------------------------------------- |
| 新闻内容重复         | 同一事件多条新闻只保留最新的一条                      |
| 经理观点过时         | 超过 30 天的观点不纳入，除非用户明确要求                |
| 热点话题 `time` 较早 | 正常展示：`time` 是文章发布时间而非上榜时间，热度排行是实时的    |
| 行业搜索无匹配        | 提示"未找到 XX 行业的相关内容，建议尝试：XX/XX/XX 等关键词" |


### 4.4 输出降级规则

当 HTML 生成遇到问题时的降级策略：


| 场景        | 降级方式                                                              |
| --------- | ----------------------------------------------------------------- |
| 行情数据缺失    | 跳过行情和温度计板块，不做占位                                                   |
| 多个数据板块无数据 | 仅保留有数据的板块 + 结构性板块（Topbar/Hero/AI核心观点/免责/页脚）；超半数板块无数据时降级为 Markdown |
| 长图生成失败    | 提示长图生成失败，提供 HTML 版本并在浏览器内引导长截图                                    |

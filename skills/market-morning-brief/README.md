# Market Morning Brief（市场早报生成器）

基于盈米MCP 插件的 AI 市场简报技能，一键生成结构化的市场速报，含行情解读、热点追踪、基金经理观点汇总、投顾内容精选。

## 能做什么

- **完整市场早报**：聚合行情、热点、资讯、经理观点、投顾精选，输出精美 HTML 简报
- **快速行情速览**：主要指数涨跌 + 市场温度计，30 秒掌握市场全貌
- **热点追踪**：按热度排序的市场话题排行榜
- **行业聚焦简报**：围绕特定行业的新闻 + 观点 + 热点专题报告
- **基金经理观点汇总**：多位经理的最新市场观点一站汇总
- **投顾内容精选**：精选优质投顾文章和策略解读
- **长图导出**：支持将 HTML 简报转为高清长图，方便分享

## 快速启动

### 方式一：完整市场早报（→ 模板一 HTML，含热点排行 + 财经新闻 + 投顾精选 + 且慢陪伴总结 + 今日关注）

```
帮我生成今天的完整市场早报 HTML：包含主要指数 KPI、热点排行（Top10）、财经新闻（国际局势/市场动态/行业政策各5条共15条）、投顾精选（5条）、且慢陪伴总结（关键词+5条启示）、今日关注（5条），给出短中长期策略建议
```

### 方式二：行情速览（→ 模板二 HTML，含指数 KPI 面板 + 涨跌概览表）

```
今天 A 股收盘了，帮我快速生成一份行情速览 HTML：展示上证、深证、创业板、沪深 300 的收盘 KPI，标出涨跌幅最大的板块和市场温度变化
```

### 方式三：行业聚焦简报（→ 模板三 HTML，含行业 KPI + 新闻卡片 + 经理观点）

```
帮我生成一份半导体行业聚焦简报 HTML：展示相关指数近期走势、行业核心新闻、重点基金经理对半导体板块的最新观点，分析后续催化剂和风险点
```

### 方式四：经理观点汇总（→ 模板四 HTML，含观点引用卡片 + 共识提炼）

```
帮我汇总最近基金经理们对后市的看法，生成 HTML 报告：每位经理一张引用卡片（含姓名、公司、核心观点原文），最后提炼多空双方的共识和分歧点
```

## 独立运行

- 本目录业务素材自包含，上传到 Coze 时无需额外业务依赖。
- HTML 报告的完整视觉参考（内联 CSS/JS）由同仓库 `../yingmi-skill/references/demo-report.html` 统一维护，生成 HTML 前必须读取该文件。

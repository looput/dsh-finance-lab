# 市场早报生成器（Market Morning Brief）

## 核心价值定位

- **不是新闻搬运工，而是智能市场简报引擎**
- 自动聚合行情数据、财经资讯、热点话题、基金经理观点、投顾精选内容
- 提炼核心要点，生成投资顾问可直接使用的结构化简报
- 支持输出精美 HTML（自包含）与高清长图，方便分享到客户群或朋友圈

## 合规边界

- 仅汇总公开市场数据和已发布的观点内容
- 所有内容**不构成投资建议**，末尾必须有免责声明
- 经理观点、投顾文章必须标注原始来源
- 不做未授权数据抓取，不泄露用户隐私

## 输入层

### 交互流程

```
用户输入 → 识别简报类型 → 调用工具获取数据 → 整合分析 → 输出简报
```

**意图识别规则**：


| 用户输入特征           | 识别为    | 简报类型  |
| ---------------- | ------ | ----- |
| "帮我生成今天的市场早报/速报" | 完整早报   | 全量聚合  |
| "今天市场怎么样"        | 行情速览   | 精简行情  |
| "最近市场有什么热点"      | 热点追踪   | 热点聚焦  |
| "XX 行业/板块最近怎么看"  | 行业聚焦   | 行业专题  |
| "基金经理怎么看后市"      | 经理观点汇总 | 观点聚合  |
| "有什么好的投顾文章/观点"   | 投顾内容精选 | 内容精选  |
| 用户指定日期           | 指定日期简报 | 按日期查询 |


### 日期处理

1. **用户未指定日期** → 调用 `GetCurrentTime` 获取当前时间，生成当日简报
2. **用户指定日期** → 使用指定日期调用工具
3. **非交易日** → `GetLatestQuotations` 自动返回最近交易日数据，简报标题标注实际数据日期

### 样式与数据隔离（强约束）

- **壳层规则见「铁律」与第零步；本条补充早报数据与核验：**
- 指数点位、涨跌幅、成交额、北向资金、热度排行等均须来自本次工具返回；不得沿用上一期早报数值。
- 时间口径必须统一：标题日期、数据截止日期、图表时间轴必须与工具返回日期一致。
- **数据真实性强约束（零容忍）**：全文见 [MCP数据真实性零容忍](../../yingmi-skill/references/MCP数据真实性零容忍.md) **§1**。
- 输出前必须执行三项核验：
  1. **时点核验**：非交易日自动落到最近交易日并显式标注；
  2. **一致性核验**：首屏 KPI 与正文表格/图表一致；
  3. **引用核验**：观点与新闻必须标注来源，不得伪造引用。

根据识别到的简报类型，从 [references/brief-playbook.md](./references/brief-playbook.md) 第一章「工具选择矩阵」选择对应工具组合。

#### 完整市场早报（全量调用）

按以下顺序调用，标注为「必调」的不可省略：


| 序号  | 工具                           | 用途                                                                                       | 优先级 |
| --- | ---------------------------- | ---------------------------------------------------------------------------------------- | --- |
| 1   | `GetCurrentTime`             | 获取当前时间                                                                                   | 必调  |
| 2   | `GetLatestQuotations`        | 各市场收盘行情 + 市场温度计                                                                          | 必调  |
| 3   | `SearchHotTopic`             | 热点排行 Top 10：不传 `publishedDate`（默认即可），接口返回的是**当前实时热度榜**，直接按返回顺序展示 Top 10；`data` 为空时不生成该板块 | 必调  |
| 4   | `SearchFinancialNews`        | 财经新闻（3 个分类各 5 条 = 共 15 条）+ 今日关注                                                          | 必调  |
| 5   | `searchRealtimeAiAnalysis`   | 且慢陪伴总结素材                                                                                 | 必调  |
| 6   | `searchInvestAdvisorContent` | 投顾精选（默认 5 条）                                                                             | 必调  |
| 7   | `SearchManagerViewpoint`     | 基金经理行业观点                                                                                 | 可选  |


其中 2/3/4 可并行调用以提高效率；5/6/7 可并行调用。

#### 首屏交付策略（时效优先，强约束）

- 完整早报采用“两阶段交付”：
  1. **首版可读稿（P0）**：优先交付行情 + 热点排行 + 财经新闻 + 策略观察；
  2. **增强版（P1/P2）**：补投顾精选、且慢陪伴总结、今日关注与导出产物。
- 当 P1/P2 工具响应慢或部分失败时，不等待全量完成；先交付首版可读稿，并显式标注“增强模块补充中/部分缺失”。
- 用户若明确要求“一次性完整成稿”，可等待增强模块，但需先回显预计等待与可能降级路径。

#### 行业聚焦简报

针对用户关注的行业/板块，所有工具 keyword 设为行业关键词：

1. `SearchFinancialNews` — 行业相关新闻
2. `SearchManagerViewpoint` — 经理对该行业的观点
3. `searchRealtimeAiAnalysis` — AI 解读中的行业分析
4. `SearchHotTopic` — 行业相关热点

### 数据整合规则

工具返回数据后，按以下规则提炼整合。详细规则见 [references/brief-playbook.md](references/brief-playbook.md) 第二章。


| 数据类型    | 提炼规则                                                                                                                                                    |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 行情数据    | 提取主要指数涨跌幅、市场温度（以实际返回字段为准）                                                                                                                               |
| 热点排行    | 直接展示 `SearchHotTopic` 返回的 Top 10（接口返回的是当前实时热度榜，`time` 为文章原始发布时间而非上榜时间）；每条：排名 + 标题（`link` 超链）+ 热度（以🔥表示或 `rank_category`）；`data` 为空时整块不生成                |
| 财经新闻    | 分三个子板块各 5 条 = **共 15 条**：【国际局势】5 条 +【市场动态】5 条 +【行业政策】5 条；每条保留分类标签 + 标题（含 url 超链接）+ 来源 + 发布时间；推荐分 3 次并行调用 `SearchFinancialNews`（按分类 keyword）以确保每个分类有足够条目 |
| 投顾精选    | 精选 5 条最新投顾内容，每条保留：标题（含 url 超链接）+ 作者 + 类型标签 + 摘要(50-100字) + 发布时间                                                                                         |
| AI 实时解读 | 提取关键词标签 + 5 条投资启示，整合为「且慢陪伴总结」板块                                                                                                                         |
| 今日关注    | 从 SearchFinancialNews 中筛选 5 条当日重要事件，每条标注时间 + 事件 + 重要性                                                                                                   |


### 投顾精选模块规则

投顾精选用于筛选高质量投顾内容推荐给读者，默认展示 5 条：

**来源优先级**（依次选取，直至凑满 5 条）：

1. `searchInvestAdvisorContent`（type = "碎碎念"，最近 24h）— 时效性最强
2. `searchInvestAdvisorContent`（type = "文章"，最近 3 天）— 深度分析
3. `searchInvestAdvisorContent`（type = "社区"，最近 7 天）— 话题讨论

**质量过滤规则**：

- 标题含"测试""占位""无标题"等关键词的直接跳过
- 同一作者最多保留 2 篇，避免单一来源主导
- 优先选取与当日行情热点**有关联**的内容（通过关键词匹配判断）

**输出格式**（每条）：

- 标题（**必须是可点击的 `<a href="url">` 超链接**）+ 作者 + 内容类型标签 + 摘要（50-100 字）+ 发布时间

**超链接规则**（适用于热点排行、财经新闻、投顾精选）：

- 所有标题必须使用 `<a href="{{url}}" target="_blank">{{title}}</a>` 格式
- url 来自 MCP 工具返回的原始链接字段，严禁编造 url
- 若工具未返回 url 字段，则标题不加超链接，仅显示纯文本

### 且慢陪伴总结生成

且慢陪伴总结替代原"AI 投顾点评"板块，基于 `searchRealtimeAiAnalysis` 返回内容生成：

**生成规则**：

1. **关键词标签云**：从 AI 解读条目中提取 5-8 个高频关键词，以标签形式展示
2. **5 条投资启示**：从解读内容中提炼 5 条核心启示，每条 1-2 句话
3. **基于实际数据**：启示必须引用 AI 解读原文中的具体信息，禁止编造
4. **语气客观**：陈述事实和现象，不做方向性预测
5. **来源标注**：每条启示标注来源解读标题

详细的生成框架见 [references/brief-playbook.md](references/brief-playbook.md) 第三章。

### 输出交付（强约束）

生成的 HTML 简报**禁止**仅保存为本地文件（如 `/workspace/xxx.html`），本地路径对飞书群/外部用户不可达。必须通过以下方式交付可在线访问的链接：

1. 生成完整的自包含 HTML 字符串（`<!DOCTYPE html>` 到 `</html>`）
2. **调用 `RenderHtmlToPdf` 工具**，将完整 HTML 作为 `html` 参数传入，`options.format` 设为 `"A4"`，`options.printBackground` 设为 `true`
3. 工具会返回一个**在线 PDF URL**，将该 URL 以 Markdown 链接形式输出给用户，例如：`[📄 点击查看且慢市场早报 PDF](https://xxx)`
4. 同时在聊天中简要总结早报核心要点（3-5 句），方便用户在点开 PDF 前快速了解

> **注意**：`RenderHtmlToPdf` 是所有简报类型的**必调**交付工具，不可省略。即使用户未主动要求 PDF，也必须调用以生成可分享链接。

### HTML 输出规则

**视觉模板**：生成 HTML 时，以 [demo-report.html](../yingmi-skill/references/demo-report.html) 为视觉基准，提取其中的 CSS 变量和组件样式完整复制进 `<style>` 标签，JS 复制进 `<script>` 标签。禁止自行发明配色、字体或组件样式。

**报告主标题（强约束）**：`<title>` 与 Hero 区 `.hero-title` 的主标题文案**固定为**「📊 且慢市场早报」（可后接 `|` 与日期星期，但主名必须为「且慢市场早报」），禁止使用单独「市场早报」作为主标题。PDF 交付链接文案建议使用「且慢市场早报 PDF」。

**实现要点（与「第零步」合并理解，不重复展开）**：壳层操作见 [HTML 视觉模板 · 生成 HTML 时](../yingmi-skill/references/HTML视觉模板.md#生成-html-时操作清单)；**禁止**自写/删减 CSS 或替换 class；图表数据须来自本次 MCP；主题切换时 ECharts `dispose()` + 重绘；涨红跌绿 `.val-up` / `.val-down`；`.ai-card` 须含 **结论 + 要点 + ⚠️ 风险提示**；整页须为完整 `<!DOCTYPE html>…</html>` 且含免责声明与页脚，视觉与 `demo-report.html` 一致。

### 运行治理

- **Q-Score 自检**：按总入口「Q-Score 通用评分细则」六维度打分，本技能附加扣分项：
  - 时效标注：行情数据未标注具体数据日期 −10
  - 模块独立性：单模块数据缺失导致整份简报为空 −15
- **重试与降级**：单工具最多重试 1 次，仍失败则降级输出（已有数据 + 缺失字段标注"数据暂未获取" + 免责声明）。
- **板块完整性**：数据板块（热点排行/财经新闻/投顾精选/且慢陪伴总结/今日关注）若 MCP 工具返回 0 条记录则整块不生成，不做空占位。结构性板块（顶栏 `report-header`（含品牌与深浅色切换）/ Hero/AI 核心观点/免责声明/页脚）必须存在。

### 板块完整性自检（必过）

- **结构性板块**（顶栏 `report-header` / Hero / 💡 AI 核心观点 / 免责声明 / 页脚）缺少任一即判定失败。
- **数据板块**（热点排行 / 财经新闻 / 投顾精选 / 且慢陪伴总结 / 今日关注等）：MCP 返回 0 条时不生成，不算缺失。
- **最小可交付骨架**：

```text
顶栏（report-header：且慢图标 + 标题/数据来源 + 深浅色切换）
Hero
💡 AI 核心观点
[有数据的板块按顺序排列]
免责声明
页脚（Powered by 盈米MCP · {{日期}}）
```

## 质量标准

- **数据时效性**：行情数据必须标注数据日期，不能模糊为"近期"
- **超链接可点击**：热点排行用 `link`、财经新闻与投顾精选用 `url` 作为 `<a href>`，点击后在新标签页打开（`rel="noopener noreferrer"`）
- **来源可追溯**：投顾内容标注作者；财经新闻标注来源和发布时间
- **热点按实时热度排序**：热点排行直接展示 `SearchHotTopic` 接口返回的 Top 10（该接口返回当前实时热度榜单，`time` 为文章原始发布时间而非上榜时间，无需按 `time` 过滤）
- **资讯有时效**：财经新闻按时间降序，优先展示最新内容；三个子分类（国际局势/市场动态/行业政策）各 5 条共 15 条
- **且慢陪伴总结**：关键词和启示必须基于 `searchRealtimeAiAnalysis` 实际返回内容，禁止编造
- **免责声明必现**：每份简报末尾必须出现免责声明

## 错误处理


| 场景                               | 处理方式                                  |
| -------------------------------- | ------------------------------------- |
| 非交易日                             | 使用最近一个交易日的行情数据，标题标注"数据截至 XX 日（最近交易日）" |
| `GetLatestQuotations` 无数据        | 跳过行情卡片区，标注"行情数据暂时不可用"，继续输出其他模块        |
| `SearchHotTopic` 返回空             | 跳过热点排行板块，不生成该区域                       |
| `SearchFinancialNews` 返回空        | 跳过财经新闻和今日关注板块，不生成                     |
| `searchInvestAdvisorContent` 返回空 | 跳过投顾精选板块，不生成                          |
| `searchRealtimeAiAnalysis` 返回空   | 跳过且慢陪伴总结板块，不生成                        |
| 多个工具连续失败                         | 用已获取数据输出简报，整体标注"部分数据源暂时不可用"           |
| 用户指定日期过早                         | 提示"该日期可能无数据覆盖，建议查询近期日期"               |
| 行业关键词无匹配                         | 提示"未找到相关行业内容，建议换用其他关键词"               |


详细的错误处理规则见 [references/brief-playbook.md](references/brief-playbook.md) 第四章。

## 注意事项

- **时间敏感**：市场早报的价值在于时效性，优先使用当日/最新数据
- **客观中立**：AI 点评只陈述事实和现象，不做"建议买入/卖出"等方向性判断
- **来源标注**：所有引用的观点和数据必须标注来源，不能当作 AI 自己的观点
- **模块降级**：某个数据板块无数据时整块不生成（不做占位），继续输出其余板块
- **并行调用**：多个无依赖的工具调用应并行执行，减少等待时间
- **免责声明**：每份简报末尾必须出现，措辞为"以上内容仅供参考，不构成投资建议"
- **在线交付**：生成 HTML 后必须调用 `RenderHtmlToPdf` 转为在线 PDF 链接，禁止仅输出本地文件路径（如 `/workspace/xxx.html`），本地路径对飞书群用户不可访问

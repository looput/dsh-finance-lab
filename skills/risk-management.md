# 风险管理技能

投资中风险控制优先于收益追求。

## 1. 风险识别

### 系统性风险
```
- 政策风险：监管变化、税收政策
- 市场风险：熊市、流动性危机
- 利率风险：加息/降息周期
- 汇率风险：本币贬值/升值
```

### 非系统性风险
```
- 个股风险：业绩暴雷、高管变动
- 行业风险：行业政策、技术颠覆
- 公司风险：财务造假、债务违约
```

## 2. 风险评估工具

### 波动率分析
```
- 历史波动率：过去20日价格标准差
- 隐含波动率：期权市场反映
- 波动率 > 30%：高风险
- 波动率 < 15%：低风险
```

### 最大回撤
```
- 计算：从高点到低点的最大跌幅
- 容忍度：建议 < 20%
- 超过25%：重新审视策略
```

### 夏普比率
```
- 计算：(收益率 - 无风险利率) / 波动率
- > 1.0：较好
- > 2.0：优秀
- < 0：不如存银行
```

## 3. 风险控制措施

### 仓位管理
```
总仓位规则：
- 牛市：70-80%
- 震荡市：50-60%
- 熊市：0-30%

个股仓位：
- 普通标的：不超过10%
- 确定性高：不超过20%
- 绝对重仓：不超过30%
```

### 止损体系
```
硬性止损：
- 单笔亏损 -8% 强制止损
- 单日亏损 -5% 停止交易

软性止损：
- 跌破重要支撑位
- 技术指标全面转空
- 基本面恶化
```

### 对冲策略
```
- 股指期货对冲
- 期权保护性认沽
- 配对交易（多强空弱）
- 现金储备
```

## 4. 风险监控清单

每日检查：
- [ ] 账户总盈亏
- [ ] 持仓个股盈亏
- [ ] 是否触发止损
- [ ] 市场重大新闻

每周检查：
- [ ] 组合波动率
- [ ] 行业配置比例
- [ ] 策略有效性
- [ ] 资金利用率

每月检查：
- [ ] 最大回撤
- [ ] 夏普比率
- [ ] 胜率统计
- [ ] 策略复盘

```

- 波动率：{percent}%
- 夏普比率：{ratio}

【持仓风险】
| 股票 | 仓位 | 盈亏 | 风险等级 |
|------|------|------|----------|
| ...  | ...  | ...  | ...      |

【集中度风险】
- 最大个股占比：{percent}%
- 最大行业占比：{percent}%
- 建议：{调整建议}

【预警提醒】
⚠️ {风险1}
⚠️ {风险2}

【风控建议】
1. {建议1}
2. {建议2}
3. {建议3}

【应急预案】
- 若市场下跌5%：{操作}

- 若触发止损：{操作}
```

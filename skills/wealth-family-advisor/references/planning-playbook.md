# 家庭理财规划决策引擎

## 一、信息采集策略

### 1.1 分阶段采集清单

#### 阶段一：家庭画像（必要信息）

每轮最多问 3-5 个问题，先采集最核心的。


| 信息项      | 是否必填 | 采集话术示例            | 默认值           |
| -------- | ---- | ----------------- | ------------- |
| 本人姓名     | 必填   | "请问您怎么称呼？"        | —             |
| 本人性别     | 必填   | "您的性别是？"          | —             |
| 本人出生日期   | 必填   | "请问您的出生年月？"       | 可接受年龄，用当前日期倒推 |
| 本人职业     | 必填   | "您目前从事什么工作？"      | —             |
| 所在城市     | 必填   | "您在哪个城市生活？"       | —             |
| 配偶信息     | 选填   | "方便提供配偶的基本信息吗？"   | 无配偶则跳过        |
| 子女信息     | 选填   | "有小朋友吗？年龄多大？"     | 无子女则跳过        |
| 父母信息     | 选填   | "需要赡养父母吗？"        | 无赡养需求则跳过      |
| 年工资收入    | 必填   | "您家庭的年工资收入大概是多少？" | —             |
| 年奖金收入    | 选填   | "有年终奖或其他奖金吗？"     | 0             |
| 其他收入     | 选填   | "有租金、投资收益等其他收入吗？" | 0             |
| 年日常花销    | 必填   | "每年日常生活开销大概多少？"   | —             |
| 房贷/车贷年支出 | 选填   | "有房贷或车贷吗？每年多少？"   | 0             |
| 教育支出     | 选填   | "有教育方面的支出吗？"      | 0             |
| 其他支出     | 选填   | "其他大项支出（保险、医疗等）？" | 0             |


#### 阶段二：资产负债（完整体检时采集）


| 信息项            | 分类    | 采集话术示例             | 默认值 |
| -------------- | ----- | ------------------ | --- |
| 流动资金（现金/活期/货基） | 流动性资产 | "手头现金和活期存款大概有多少？"  | —   |
| 定期存款/大额存单      | 投资性资产 | "有定期存款吗？"          | 0   |
| 基金/策略          | 投资性资产 | "持有基金或理财产品吗？总额多少？" | 0   |
| 股票             | 投资性资产 | "有炒股吗？市值多少？"       | 0   |
| 银行理财/债券        | 投资性资产 | "有银行理财或债券吗？"       | 0   |
| 储蓄型保险          | 投资性资产 | "有储蓄型/年金保险吗？"      | 0   |
| 个人养老金          | 投资性资产 | "有开通个人养老金账户吗？"     | 0   |
| 投资房产           | 投资性资产 | "有投资用的房产吗？市值多少？"   | 0   |
| 其他投资（股权/贵金属等）  | 投资性资产 | "有其他投资吗？"          | 0   |
| 自住房            | 自用性资产 | "自住房市值大概多少？"       | 0   |
| 车辆             | 自用性资产 | "有车吗？大概值多少？"       | 0   |
| 车位             | 自用性资产 | "有车位吗？"            | 0   |
| 自住房贷款          | 自用性负债 | "房贷还剩多少没还？"        | 0   |
| 车贷             | 自用性负债 | "车贷余额多少？"          | 0   |
| 车位贷            | 自用性负债 | "车位有贷款吗？"          | 0   |
| 投资房贷款          | 投资性负债 | "投资房产有贷款吗？"        | 0   |
| 其他投资贷款         | 投资性负债 | "有借钱投资吗？"          | 0   |
| 信用卡            | 流动性负债 | "信用卡欠款多少？"         | 0   |
| 个人借贷（花呗/白条等）   | 流动性负债 | "有花呗/白条/网贷等欠款吗？"   | 0   |
| 其他借款           | 流动性负债 | "有其他借款吗？"          | 0   |


#### 阶段三：规划目标（目标规划时采集）


| 信息项        | 采集话术示例                          | 默认值 |
| ---------- | ------------------------------- | --- |
| 风险偏好（最大回撤） | "您能接受的最大亏损是多少？比如 10%？"          | —   |
| 期望收益率      | "期望的年化收益率大概多少？"                 | —   |
| 投资期限       | "这笔钱大概打算投多久？"                   | —   |
| 具体目标       | "有没有具体的财务目标？比如 X 年后买房/孩子上学/退休？" | —   |
| 目标金额       | "大概需要多少钱？"                      | —   |


### 1.2 默认值处理规则


| 场景           | 处理方式                    |
| ------------ | ----------------------- |
| 用户给了年龄而非出生日期 | 用当前年份 - 年龄，月日默认 1 月 1 日 |
| 用户说"月薪 X 万"  | 自动换算为年收入（× 12），并确认是否含税  |
| 用户说"大概""差不多" | 按给出的数字处理，在报告中标注"基于估算数据" |
| 某项资产/负债未提及   | 默认为 0，不主动追问非核心项         |
| 用户提供了部分数据    | 用已有数据分析，报告标注"基于已提供数据"   |


### 1.3 数据校验规则


| 校验项              | 规则    | 触发动作                             |
| ---------------- | ----- | -------------------------------- |
| 年支出 > 年收入        | 异常    | 温和确认："您的年支出大于收入，请问是否有其他收入来源未统计？" |
| 流动性资产 = 0 且有高额负债 | 高风险信号 | 提示关注紧急备用金                        |
| 年龄 < 18 且有工资收入   | 可能误填  | 确认年龄是否正确                         |
| 年龄 > 65 且有大额房贷   | 不常见   | 确认数据是否正确                         |
| 总资产为 0 但有投资收入    | 矛盾    | 提示补充资产信息                         |
| 同一项目重复提供         | 数据冲突  | 以最新提供的数据为准，告知用户                  |

## 二、工具选择矩阵

### 2.1 按场景选择工具

#### 完整规划流程


| 步骤      | 工具                             | 何时调用           | 必要性    |
| ------- | ------------------------------ | -------------- | ------ |
| 1. 家庭画像 | `AnalyzeFamilyMembers`         | 采集完阶段一信息后      | 必调     |
| 2. 收支分析 | `AnalyzeIncomeExpense`         | 有收支数据后         | 必调     |
| 3. 资产负债 | `AnalyzeAssetLiability`        | 有资产负债数据后       | 财务体检必调 |
| 4. 财务指标 | `AnalyzeFinancialIndicators`   | 收支 + 资产负债数据齐备后 | 财务体检必调 |
| 5. 现金流  | `AnalyzeCashFlow`              | 用户有目标规划需求时     | 目标规划必调 |
| 6. 配置方案 | `GetAssetAllocationPlan`       | 用户需要配置建议时      | 配置方案必调 |
| 7. 方案落地 | `GetCompositeModel`            | 获得配置方案 ID 后    | 配置方案必调 |
| 8. 方案评估 | `AnalyzeInvestmentPerformance` | 方案生成后          | 可选     |
| 9. 蒙特卡洛 | `MonteCarloSimulate`           | 用户想了解概率分布时     | 可选     |


#### 单项分析模式


| 用户需求           | 需要调用的工具                                                                         |
| -------------- | ------------------------------------------------------------------------------- |
| 只要收支分析         | `AnalyzeIncomeExpense`                                                          |
| 只要资产负债         | `AnalyzeAssetLiability`                                                         |
| 收支 + 资产负债 + 指标 | `AnalyzeIncomeExpense` → `AnalyzeAssetLiability` → `AnalyzeFinancialIndicators` |
| 只要配置方案         | `GetAssetAllocationPlan` → `GetCompositeModel`                                  |
| 目标规划           | `AnalyzeFamilyMembers` → `AnalyzeCashFlow`                                      |


### 2.2 各工具参数说明

#### `AnalyzeFamilyMembers`

输入（familyMembers 数组，每个成员包含）：


| 参数            | 类型     | 必填  | 说明                                   |
| ------------- | ------ | --- | ------------------------------------ |
| role          | string | 是   | 可选值：本人/配偶/儿子/女儿/父亲/母亲/岳父/公公/岳母/婆婆/亲属 |
| name          | string | 是   | 姓名                                   |
| gender        | string | 是   | 男/女                                  |
| birthDate     | string | 是   | YYYY-MM-DD 格式                        |
| occupation    | string | 是   | 职业                                   |
| residenceCity | string | 是   | 居住城市                                 |


输出：家庭总人数、成年/未成年人数、生命周期阶段。

#### `AnalyzeIncomeExpense`

输入：


| 参数            | 分类  | 包含字段                                                                                                                                                                                                                            |
| ------------- | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| annualIncome  | 年收入 | salary（工资）、bonus（奖金）、rentalIncome（租金）、housingFundWithdrawal（公积金提取）、investmentIncome（投资收入）、businessIncome（经营收入）、otherIncome（其他）                                                                                                  |
| annualExpense | 年支出 | dailyExpenses（日常花销）、utilityBills（生活缴费）、transportation（交通）、mortgagePayment（房贷）、carLoanPayment（车贷）、parkingLoanPayment（车位贷）、insurancePremium（保障型保费）、educationExpenses（教育）、medicalExpenses（医疗）、travelExpenses（旅行）、otherExpenses（其他） |


输出：总收入、总支出、年度结余、各项占比、月度必要性支出。

#### `AnalyzeAssetLiability`

输入：


| 参数层级                                    | 分类    | 包含字段                                                                                  |
| --------------------------------------- | ----- | ------------------------------------------------------------------------------------- |
| totalAssets.liquidAssets                | 流动性资产 | cash（流动资金）                                                                            |
| totalAssets.investmentAssets            | 投资性资产 | fixedDeposit、bankFinance、fund、stock、savingsInsurance、pension、investmentProperty、other |
| totalAssets.personalUseAssets           | 自用性资产 | residentialProperty、vehicle、parkingSpace                                              |
| totalLiabilities.personalUseLiabilities | 自用性负债 | residentialPropertyLoan、carLoan、parkingSpaceLoan                                      |
| totalLiabilities.investmentLiabilities  | 投资性负债 | investmentMortgage、investmentLoans                                                    |
| totalLiabilities.currentLiabilities     | 流动性负债 | creditCard、personalLoan、other                                                         |


输出：资产负债总览、各类资产/负债占比、净资产。

#### `AnalyzeFinancialIndicators`

输入（全部必填）：


| 参数                      | 说明     | 数据来源                    |
| ----------------------- | ------ | ----------------------- |
| totalAssets             | 总资产    | 资产负债分析结果                |
| totalLiabilities        | 总负债    | 资产负债分析结果                |
| liquidAssets            | 流动性资产  | 资产负债分析结果                |
| currentLiabilities      | 流动性负债  | 资产负债分析结果                |
| investmentAssets        | 投资性资产  | 资产负债分析结果                |
| investmentLiabilities   | 投资性负债  | 资产负债分析结果                |
| annualIncome            | 年收入    | 收支分析结果                  |
| annualExpense           | 年支出    | 收支分析结果                  |
| annualInvestmentIncome  | 年投资收入  | 收支分析中的 investmentIncome |
| monthlyEssentialExpense | 月必要性支出 | 收支分析结果                  |


输出：7 大指标及状态评估。

#### `AnalyzeCashFlow`

输入：


| 参数                      | 类型     | 说明                             |
| ----------------------- | ------ | ------------------------------ |
| currentInvestableAssets | number | 当前可投资产（流动性 + 投资性资产合计）          |
| returnRateConfig        | array  | 报酬率配置（按年龄段设置不同回报率）             |
| familyMembers           | array  | 家庭成员（role + name + initialAge） |
| continuousIncome        | array  | 持续性收入（类型 + 起止年龄 + 金额 + 增长率）    |
| continuousExpenses      | array  | 持续性支出（类型 + 起止年龄 + 金额 + 通胀率）    |
| oneTimeIncome           | array  | 一次性收入（类型 + 年龄 + 金额）            |
| oneTimeExpenses         | array  | 一次性支出（类型 + 年龄 + 金额）            |


收入类型枚举：salary / bonus / rentalIncome / housingFundWithdrawal / investmentIncome / businessIncome / otherIncome

支出类型枚举：dailyExpenses / utilityBills / transportation / mortgagePayment / carLoanPayment / parkingLoanPayment / insurancePremium / educationExpenses / medicalExpenses / travelExpenses / otherExpenses

输出：各年度收入/支出/结余/累计资产、关键目标节点标注。

#### `GetAssetAllocationPlan`

输入（至少传一个）：


| 参数                           | 类型     | 说明                                                           |
| ---------------------------- | ------ | ------------------------------------------------------------ |
| expectedAnnualizedReturnRate | number | 预期年化收益率，如 0.05 = 5%                                          |
| expectedDrawdown             | number | 预期最大回撤，如 0.02 = 2%                                           |
| expectedInvestTime           | string | 投资期限枚举：spare / oneYear / oneToThree / threeToFive / overFive |


输出：六大类资产权重 + 配置方案 ID（assetPlanId）。

#### `GetCompositeModel`

输入：


| 参数          | 类型     | 说明                                   |
| ----------- | ------ | ------------------------------------ |
| assetPlanId | string | 来自 `GetAssetAllocationPlan` 返回的方案 ID |


输出：每个资产大类对应的具体基金代码、基金名称、配置比例。

#### `AnalyzeInvestmentPerformance`

输入：


| 参数                    | 类型     | 说明                                                        |
| --------------------- | ------ | --------------------------------------------------------- |
| totalInvestableAssets | number | 可投入资产总额                                                   |
| shortMediumTermScheme | object | 中短期方案（type + investmentAmount + annualReturn）             |
| mediumLongTermScheme  | object | 中长期方案（type + investmentAmount + annualReturn），金额 ≤ 0 时可不传 |
| expectedReturnRate    | number | 期望报酬率，默认 0.04                                             |


输出：方案可行性分析、加权收益率、配置权重分析。

#### `MonteCarloSimulate`

输入：


| 参数              | 类型     | 说明                                                                                             |
| --------------- | ------ | ---------------------------------------------------------------------------------------------- |
| weights         | object | 六大类资产权重：equity、fixedIncome、overseasEquity、overseasFixedIncome、commodity、cash（均为 0-1 小数，合计 = 1） |
| periodCount     | number | 模拟周期（年），最小 1                                                                                   |
| frequency       | string | 模拟频率：YEAR / MONTH / WEEK / DAY                                                                 |
| simulationCount | number | 模拟次数，最小 1000                                                                                   |


输出：各百分位收益率、预期收益分布、波动率情景、可视化图表 URL。

## 三、数据解读规则

### 3.1 财务指标解读标准

以下为 `AnalyzeFinancialIndicators` 返回的 7 大指标解读标准。每个指标必须给出状态判断 + 文字解读。


| 指标    | 合理范围  | 预警范围    | 危险范围  | 解读模板                                     |
| ----- | ----- | ------- | ----- | ---------------------------------------- |
| 资产负债率 | < 50% | 50%-70% | > 70% | "您的资产负债率为 {X}%，{状态描述}。参考标准为 50% 以下较为健康。" |
| 流动比率  | > 3   | 1-3     | < 1   | "流动比率 {X}，{状态描述}。建议保持 3 倍以上的流动性覆盖。"      |
| 融资比率  | < 40% | 40%-60% | > 60% | "融资比率 {X}%，{状态描述}。反映投资中借贷占比。"            |
| 即付比率  | > 70% | 30%-70% | < 30% | "即付比率 {X}%，{状态描述}。衡量短期偿债能力。"             |
| 结余比率  | > 30% | 10%-30% | < 10% | "年度结余率 {X}%，{状态描述}。建议至少保持 30% 的储蓄率。"     |
| 投资回报率 | 视情况   | —       | —     | "投资回报率 {X}%，{状态描述}。"                     |
| 自由储蓄率 | > 20% | 10%-20% | < 10% | "自由储蓄率 {X}%，{状态描述}。这是扣除必要支出后的真实储蓄能力。"    |


状态标签：

- 合理范围 → ✅ 健康 / "处于合理范围"
- 预警范围 → ⚠️ 关注 / "略偏高/偏低，建议关注"
- 危险范围 → 🔴 预警 / "已超出合理范围，建议优先调整"

### 3.2 生命周期阶段特征与建议


| 阶段             | 典型特征             | 财务重点            | 配置风格建议        |
| -------------- | ---------------- | --------------- | ------------- |
| 单身期（22-28 岁）   | 收入增长快，支出灵活，无家庭负担 | 强制储蓄习惯养成，紧急备用金  | 可偏积极，权益占比可较高  |
| 家庭形成期（25-35 岁） | 结婚、购房、收入上升，负债增加  | 购房规划、保障配置、控制负债率 | 稳健偏积极，注意流动性   |
| 家庭成长期（30-45 岁） | 子女教育支出增加，收入高峰前期  | 教育金规划、保障完善、加速储蓄 | 均衡配置，兼顾增长和安全  |
| 家庭成熟期（40-55 岁） | 收入高峰，子女逐渐独立      | 养老规划、资产增值、降低负债  | 逐步降低风险，增加固收比例 |
| 退休前期（50-65 岁）  | 收入开始下降，养老需求紧迫    | 养老金储备冲刺、资产保全    | 偏稳健，权益比例不宜过高  |
| 退休期（60 岁+）     | 固定收入为主，支出下降      | 资产保值、现金流管理、医疗储备 | 保守为主，流动性优先    |


### 3.3 资产配置风格对应表


| 用户特征        | 推荐配置倾向    | 参考参数                    |
| ----------- | --------- | ----------------------- |
| 保守型（不能亏）    | 固收为主，少量权益 | 预期回撤 ≤ 2%，投资期限 oneYear  |
| 稳健型（小亏可接受）  | 固收 + 适量权益 | 预期回撤 5%，期限 oneToThree   |
| 平衡型（能承受波动）  | 权益固收均衡    | 预期回撤 10%，期限 threeToFive |
| 积极型（追求收益）   | 权益为主      | 预期回撤 15-20%，期限 overFive |
| 激进型（高风险高收益） | 高权益 + 商品  | 预期回撤 > 20%，期限 overFive  |


### 3.4 收支解读规则


| 指标             | 健康标准 | 解读用语                    |
| -------------- | ---- | ----------------------- |
| 结余率 > 30%      | 优秀   | "储蓄能力强，具备良好的财富积累基础"     |
| 结余率 20%-30%    | 良好   | "储蓄率尚可，可尝试优化支出结构"       |
| 结余率 10%-20%    | 一般   | "储蓄空间有限，建议梳理非必要支出"      |
| 结余率 < 10%      | 偏弱   | "结余率较低，建议优先优化支出或增加收入来源" |
| 房贷占收入 > 50%    | 偏高   | "房贷压力较大，注意现金流安全"        |
| 日常开销占收入 > 40%  | 偏高   | "日常开销占比较高，可检视是否有优化空间"   |
| 单一收入来源占比 > 80% | 集中   | "收入来源较单一，建议逐步拓展其他收入渠道"  |

## 四、错误处理与边界场景

### 4.1 信息采集阶段


| 场景                  | 处理方式                        |
| ------------------- | --------------------------- |
| 用户不愿提供某项信息          | 尊重用户选择，跳过该项，标注"未提供"，用已有数据分析 |
| 用户提供模糊数据（"大概""差不多"） | 按给出数字处理，报告标注"基于估算数据"        |
| 用户反复修改数据            | 以最新数据为准，不保留历史版本             |
| 用户一次性提供所有数据         | 跳过渐进式采集，直接进入分析              |
| 用户提供了超出问题范围的信息      | 识别并归类到对应字段，不遗漏              |


### 4.2 数据异常场景


| 场景            | 处理方式                                 |
| ------------- | ------------------------------------ |
| 年支出 > 年收入 × 2 | 提示确认："您的年支出约为年收入的 X 倍，请问是否有遗漏的收入来源？" |
| 负债 > 资产 × 3   | 提示关注："当前负债水平较高，建议优先关注债务管理"           |
| 流动性资产 = 0     | 在报告中重点提示紧急备用金不足的风险                   |
| 所有资产集中在一类     | 在配置建议中强调分散化                          |
| 投资性负债占比极高     | 提示杠杆风险，建议谨慎                          |


### 4.3 工具调用异常


| 场景                                | 处理方式                       |
| --------------------------------- | -------------------------- |
| `AnalyzeFamilyMembers` 调用失败       | 跳过生命周期分析，后续分析正常进行          |
| `AnalyzeIncomeExpense` 调用失败       | 无法进行收支分析，提示用户稍后重试          |
| `AnalyzeAssetLiability` 调用失败      | 无法进行资产负债分析，用已有数据输出         |
| `AnalyzeFinancialIndicators` 调用失败 | 跳过指标评估，标注"财务指标评估暂时不可用"     |
| `AnalyzeCashFlow` 调用失败            | 跳过现金流模拟，标注缺失               |
| `GetAssetAllocationPlan` 调用失败     | 无法生成配置方案，提示用户稍后重试          |
| `GetCompositeModel` 调用失败          | 展示资产大类权重，标注"具体基金推荐暂时不可用"   |
| 多个工具连续失败                          | 输出已获取的数据，整体标注"部分分析模块暂时不可用" |


### 4.4 特殊场景


| 场景                | 处理方式                             |
| ----------------- | -------------------------------- |
| 用户只有负债没有资产        | 以债务管理为核心给出建议，不强行推荐投资方案           |
| 用户年龄 > 70         | 配置方案以保守/超保守为主，强调流动性和安全性          |
| 用户收入为 0（全职妈妈/学生等） | 基于家庭整体收入分析，不做个人收入评价              |
| 用户目标金额远超现有资产和收入   | 如实告知差距，建议调整目标或延长时间               |
| 用户同时要做多个目标规划      | 按优先级排序（紧急备用金 > 保障 > 短期目标 > 长期目标） |
| 现金流模拟显示资金断裂       | 明确标注断裂年份，建议调整支出/目标/增加收入          |

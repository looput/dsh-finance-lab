# wealth-family-advisor（财富规划顾问）

基于盈米MCP 插件的 AI 家庭理财规划技能，从了解家庭基本情况到给出可落地的资产配置方案，覆盖完整的理财规划工作流。

## 能做什么

- **完整家庭财务规划**：从信息采集到最终配置方案的全流程服务
- **收支分析**：收入结构、支出结构、结余率分析及解读
- **资产负债梳理**：三类资产 + 三类负债分类整理，计算净资产和财务健康度
- **财务健康体检**：7 大关键指标评估（资产负债率、流动比率、融资比率等），每个指标都有文字解读
- **目标规划**：基于现金流模拟的购房/教育/养老等目标可行性分析
- **资产配置方案**：根据风险偏好生成六大类资产权重，落地到具体基金和金额
- **蒙特卡洛模拟**：模拟未来收益概率分布，量化风险

## 快速启动

### 方式一：完整家庭财务规划（→ 模板一 HTML，含收支饼图 + 资产负债表 + 配置雷达 + 目标时间线）

```
我家年收入 50 万（工资 40 万 + 奖金 10 万），年支出 30 万（房贷 12 万 + 日常 10 万 + 教育 5 万 + 其他 3 万），有房产 300 万、存款 80 万、基金 40 万，房贷余额 150 万。帮我生成一份完整的家庭财务规划 HTML 报告：包含收支结构饼图、资产负债全景表、财务健康度 KPI、配置建议和基金落地方案
```

### 方式二：收支分析专项（→ 模板二 HTML，含收入/支出结构饼图 + 结余率 KPI）

```
帮我分析一下家庭收支：月工资 3 万、房贷月供 1.2 万、日常开销 8000、教育支出 3000、保险 2000。生成 HTML 报告展示收支结构占比饼图和结余率指标，标出可优化的弹性支出
```

### 方式三：退休目标规划（→ 模板一 HTML，含目标缺口分析 + 定投路径模拟）

```
我 35 岁想在 50 岁退休，目前可投资产 200 万，每年能存 20 万。帮我算一下退休资金缺口，生成 HTML 规划报告：展示目标金额测算过程、每年所需定投金额、推荐的配置比例和具体基金方案
```

### 方式四：配置方案专项（→ 模板四 HTML，含配置比例图 + 基金推荐卡片）

```
我有 100 万可投资，能承受 15% 回撤，期望年化 8%，投资期限 3-5 年。帮我生成一份配置方案 HTML：展示各类资产建议配比、具体推荐基金的业绩和风险指标卡片，附上再平衡建议
```

## 独立运行

- 本目录业务素材自包含，上传到 Coze 时无需额外业务依赖。
- HTML 报告的完整视觉参考（内联 CSS/JS）由同仓库 `../yingmi-skill/references/demo-report.html` 统一维护，生成 HTML 前必须读取该文件。

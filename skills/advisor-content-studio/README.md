# Advisor Content Studio（投顾内容工坊）

基于盈米MCP 插件的 AI 投顾内容创作技能，帮投资顾问、理财顾问和运营人员快速创作有数据支撑的专业内容。

## 能做什么

- **选题发现**：扫描热点话题、财经资讯、AI 解读、已有投顾内容，输出选题建议清单
- **市场解读**：基于真实行情数据 + 经理观点 + 财经资讯，创作专业市场分析文章
- **基金推荐**：基于基金业绩、风险、持仓的数据分析，创作有数据支撑的推荐文案
- **投教科普**：用通俗语言解释投资概念和策略，降低投资者理解门槛
- **热点评论**：基于热点话题的快速评论，抢占内容时效性
- **短文案**：朋友圈 / 社群分享的精炼文案，可直接复制使用
- **精美排版**：输出专业金融杂志风格的 HTML/长图，支持 ECharts 数据图表

## 快速启动

### 方式一：市场解读（→ 模板一 HTML，含 ECharts 图表）

```
帮我写一篇今天 A 股的市场解读，要求包含主要指数 KPI、板块涨跌幅柱状图、近 5 日成交额和北向资金走势图，引用 2-3 位基金经理的最新观点，最后给出短中长期策略建议，输出完整 HTML 页面
```

### 方式二：基金推荐（→ 模板二 HTML，含基金卡片 + 业绩对比图）

```
帮我从红利低波方向挑 3 只基金，生成一篇推荐文 HTML：每只基金要有独立卡片展示近 1 年收益、最大回撤、夏普比率和基金经理信息，再用柱状图横向对比各阶段业绩，附上风险提示
```

### 方式三：投教科普（→ 模板三 HTML，含误区纠正卡片）

```
帮我写一篇"定投真的能无脑赚钱吗"的投教科普 HTML，用"常见误区 → 正确理解"的对比卡片拆解 3 个典型认知偏差，配上实用建议清单
```

### 方式四：热点评论（→ 模板四 HTML，含经理观点引用卡）

```
今天央行意外降准，帮我快速生成一篇热点评论 HTML，分析对债市和权益市场的短期影响，引用相关基金经理观点，给出投资者应对建议
```

### 方式五：短文案（→ 模板五 HTML 精简卡片）

```
今天沪深 300 跌了 1.5%，帮我生成 3 条引导客户逆向定投的朋友圈文案卡片，分别用数据理性风、温暖陪伴风、轻松幽默风，每条 80 字以内
```

## 文件结构

```text
advisor-content-studio/
├── README.md                         # 本文件
├── SKILL.md                          # 技能主文件（交互流程 + 处理逻辑 + 输出规范 + 质量标准）
├── references/
│   ├── content-playbook.md           # 内容创作引擎（素材工具矩阵 + 写作框架 + 排版规则 + 合规红线 + 错误处理）
│   └── report-templates.md           # 输出模板（通用 HTML 基座 + 5 种内容类型板块 HTML + Markdown 模板）
```

## 独立运行

- 本目录业务素材自包含，上传到 Coze 时无需额外业务依赖。
- HTML 报告的完整视觉参考（内联 CSS/JS）由同仓库 `../yingmi-skill/references/demo-report.html` 统一维护，生成 HTML 前必须读取该文件。

## 依赖

- **盈米MCP 插件**：提供行情数据、基金分析、财经资讯、经理观点、热点话题等 API 工具

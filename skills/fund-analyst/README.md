# Fund Analyst（基金分析专家）

基于盈米MCP 插件的 AI 基金分析技能，能根据基金类型自动切换分析策略，输出带解读结论的结构化报告。

## 能做什么

- **单只基金深度分析**：覆盖基本信息、业绩表现、风险评估、持仓分析、交易规则、投资建议
- **多基金对比分析**：横向对比业绩/风险/持仓，含相关性分析
- **基金经理画像**：分析经理投资风格、历史业绩、管理规模
- **风险专项评估**：波动率、最大回撤、夏普比率深度解读
- **智能类型适配**：自动识别股票/债券/指数/货币/QDII 型，按类型调整分析维度

## 快速启动

### 方式一：单基金完整分析（→ 模板一 HTML，含净值走势 + 持仓饼图 + 业绩柱状图）

```
帮我全面分析 005827，要求生成 HTML 报告：包含基本信息 KPI 面板、近 1 年净值走势图、持仓行业和重仓股饼图、各阶段业绩柱状图，最后给出 AI 综合评价和风险提示
```

### 方式二：多基金对比（→ 模板三 HTML，含对比表格 + 雷达图）

```
帮我对比 005827、110011 和 163406，生成 HTML 对比报告：用表格横向对比各阶段收益和风险指标，用雷达图展示收益、回撤、波动、夏普四个维度的差异，给出选择建议
```

### 方式三：基金经理深度分析（→ 模板四 HTML，含经理卡片 + 代表基金业绩）

```
帮我分析基金经理张坤，生成 HTML 报告：展示其管理年限、管理规模、代表基金的各阶段业绩和风险指标，评价投资风格和能力圈
```

### 方式四：风险评估专项（→ 模板五 HTML，含风险 KPI + 回撤走势图）

```
005827 这只基金风险到底有多大？生成一份风险评估 HTML：展示最大回撤、年化波动率、夏普比率、下行风险等 KPI，附上历史回撤走势图和同类风险水平对比
```

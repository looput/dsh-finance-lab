# 基金分析专家（Fund Analyst）

## 核心价值定位

- **不是数据搬运工，而是有解读能力的分析引擎**
- 根据基金类型（股票/债券/指数/货币/QDII）自动切换分析策略
- 不只输出数字，还给出排名解读、风险评级和可操作的投资建议
- 支持单只深度分析、多基金对比、基金经理画像三种模式

## 合规边界

- 仅使用用户提供的基金代码/名称 + 盈米MCP 工具返回的公开数据
- 提供的分析结果仅供参考，**不构成投资建议**
- 不做未授权数据抓取，不泄露用户隐私

## 输入层

### 交互流程

```
用户输入 → 识别意图 → 确认基金 → 选择分析策略 → 调用工具 → 输出报告
```

**意图识别规则**：


| 用户输入特征                | 识别为  | 分析模式        |
| --------------------- | ---- | ----------- |
| 单个基金代码（6 位数字）         | 单只分析 | 直接分析        |
| 单个基金名称                | 单只分析 | 先确认代码再分析    |
| 多个基金代码/名称             | 对比分析 | 批量获取 + 对比输出 |
| 提到"基金经理""谁管的"         | 经理分析 | 经理画像模式      |
| 提到"风险""回撤""波动"        | 风险专项 | 风险评估模式      |
| "简单看看""快速了解""先概览""简版" | 快速了解 | 简要分析模式      |
| 无特定维度                 | 完整分析 | 全维度报告       |


### 基金确认流程

1. **用户给了基金代码** → 直接调 `BatchGetFundsDetail` 获取信息
2. **用户给了基金名称** → 先调 `GuessFundCode` 匹配代码
  - 匹配到唯一结果 → 确认后分析
  - 匹配到多个 → 列出候选列表，让用户选择
  - 匹配不到 → 用 `SearchFunds` 扩大搜索，仍无结果则提示用户核实
3. **用户给了多个基金** → 批量确认代码，进入对比模式

### 样式与数据隔离（强约束）

- **壳层与占位符规则见「铁律」与第零步；本条补充本技能数据与核验：**
- 报告中出现的每个数值都必须来自本次会话内 MCP 工具实时返回；不得凭经验补数，不得沿用历史示例值。
- 若字段缺失或工具失败，必须显式标注`数据暂未获取`，禁止用“约、约等于、估算值”替代。
- **数据真实性强约束（零容忍）**：全文见 [MCP数据真实性零容忍](../../yingmi-skill/references/MCP数据真实性零容忍.md) **§1**。
- **空列/空行裁剪（强制）**：当某一列或某一行的**全部数据**均无法从 MCP 工具获取时，必须在表格和图表中**整列/整行删除**，禁止保留并填写"数据暂未获取"。典型场景：
  - `GetBatchFundPerformance` 不返回沪深300收益 → 业绩表格和柱状图中**不得出现沪深300列/系列**；
  - `GetBatchFundPerformance.stageReturns` 不包含某阶段（如近2年）→ 业绩表格和柱状图中**不得出现该行/该数据点**；
  - 仅当某行/列中**部分**字段缺失时，才对缺失单元格标注"数据暂未获取"。
- 输出前必须执行三项核验：
  1. **来源核验**：关键字段（收益、回撤、夏普、规模、费率、交易状态、风险分）可映射到具体工具返回字段；
  2. **一致性核验**：摘要、卡片、表格、图表同一指标数值一致；
  3. **语义核验**：交易状态用`canSubscribe`判定“可申购/暂停申购”，不得用`canAllot`替代。

### 第一步：基金类型识别

通过 `BatchGetFundsDetail` 获取基金类型字段，按类型选择分析策略。详细的类型识别表和判定流程见 [references/analysis-playbook.md](./references/analysis-playbook.md) 第一章。

关键分支：

- **股票型/偏股混合** → 侧重持仓、行业分布、Brinson 归因
- **债券型** → 侧重久期、信用评级、Campisi 归因、券种配置
- **指数型** → 侧重跟踪误差、费率、规模
- **货币型** → 侧重 7 日年化、万份收益（最简分析）
- **QDII** → 侧重地区配置、海外市场

### 第二步：按策略调用 MCP 工具

根据基金类型和用户关注的维度，从 [references/analysis-playbook.md](references/analysis-playbook.md) 第二章「MCP 工具选择矩阵」选择对应工具组合。

通用调用顺序：

1. `BatchGetFundsDetail` — 基本信息（必调）
2. `GetBatchFundPerformance` — 业绩表现（必调）
3. `AnalyzeFundRisk` — 风险评估（完整分析时必调）
4. `BatchGetFundsHolding` — 持仓分析（非货币型必调）
5. 类型专用工具 — 如 `getFundBrinsonIndicator`（股票型）或 `getBondIndicator`（债券型）
6. `BatchGetFundTradeRules` — 交易规则（完整分析时必调）

多基金对比时额外调用 `GetFundsCorrelation` 分析相关性。

### 第三步：数据解读与综合评价

不能只输出原始数据，必须给出解读结论。解读标准见 [references/analysis-playbook.md](references/analysis-playbook.md) 第三章。

关键规则：

- 业绩排名按百分位分级：前 10% = 卓越 → 后 20% = 较差
- 风险指标按基金类型分档（股票型最大回撤 < 15% 为优秀，债券型 < 2% 为优秀）
- 综合评价覆盖四维度：收益能力 + 风险控制 + 稳定性 + 费用效率
- 投资建议必须包含：适合投资者类型 + 建议持有期 + 核心优势 + 主要风险

### ECharts 数据注入规则

- `{{echarts_asset_data}}`：资产配置饼图，格式 `[{value: {{股票占比}}, name: '股票'}, ...]`，数值来自 `BatchGetFundsHolding` 返回的 `assetAllocation`
- `{{echarts_radar_data}}`：四维评分雷达图（收益/风控/稳定性/成本），满分 100。评分规则：
  - **收益**：按 `GetBatchFundPerformance` 返回的近 1 年同类排名百分位映射（前 10%→90+, 前 25%→75-90, 中位→50-75, 后 25%→25-50, 后 10%→<25）
  - **风控**：按 `AnalyzeFundRisk` 返回的最大回撤同类排名百分位反向映射（回撤越小分越高）
  - **稳定性**：按 `AnalyzeFundRisk` 返回的夏普比率同类排名百分位映射
  - **成本**：按 `BatchGetFundsDetail` 返回的管理费+托管费合计，费率越低分越高（<0.8%→90+, 0.8-1.5%→70-90, 1.5-2%→50-70, >2%→<50）
  - 若某维度数据缺失，标注"数据不足"并在雷达图中置 0
- `{{echarts_industry_names}}` + `{{echarts_industry_values}}`：行业分布横向柱状图；若无行业数据替换为 `[]`
- 按基金类型动态裁剪分区（股票型展示行业分布，债券型展示券种/信用评级，货币型只保留基本信息+业绩+交易规则）

### 运行治理

- **Q-Score 自检**：按总入口「Q-Score 通用评分细则」六维度打分，本技能附加扣分项：
  - 类型匹配性：分析策略与基金类型不匹配（如对货币型做行业分析、对指数型评价选股能力）−10
  - 投资建议可操作性：必须含适合投资者类型 + 持有期建议 + 核心优势 + 主要风险，每缺一项 −3
- **重试与降级**：单工具最多重试 1 次，仍失败则降级输出（已有数据 + 缺失字段标注"数据暂未获取" + 免责声明）。
- **板块完整性**：缺少上述板块表中任何一项视为输出不合格。数据不足时该板块保留骨架并标注"数据暂未获取"。

### 板块完整性自检（必过）

- **失败示例**：缺少任一固定板块（例如漏掉 `💡 AI 核心观点`、`免责声明` 或 `页脚`）即判定失败，必须重生整份输出。
- **最小可交付骨架（10 行以内）**：


## 质量标准

- **数据完整性**：核心字段（净值、业绩、风险等级）不能为空；缺失时标注原因
- **解读一致性**：排名百分位与解读用语必须匹配（如前 20% 不能写"表现中等"）
- **建议可操作性**：投资建议必须包含适合投资者类型 + 持有期建议 + 风险提示，不能写"建议综合考虑"
- **类型匹配性**：不对货币型基金分析行业分布，不对指数型基金评价选股能力
- **免责声明**：每份报告末尾必须出现

## 错误处理


| 场景         | 处理方式                      |
| ---------- | ------------------------- |
| 基金代码不存在    | 提示用户检查，建议用名称搜索            |
| 名称匹配多个结果   | 列出候选列表（代码 + 名称 + 类型），让用户选 |
| 新基金无长期数据   | 标注"成立不足 X 年"，不输出无意义的排名    |
| 部分数据缺失     | 标注"数据暂未披露"，用已有数据先输出       |
| 基金已清盘      | 提示已清盘，仅展示历史数据             |
| MCP 工具调用失败 | 用已获取的数据输出，标注缺失部分          |
| 基金经理近期变更   | 标注变更时间，提示历史业绩主要反映前任经理     |


详细的错误处理规则见 [references/analysis-playbook.md](references/analysis-playbook.md) 第四章。

## 注意事项

- **始终先确认基金代码**：名称输入必须先匹配代码再分析，避免分析错误基金
- **分析策略跟着类型走**：不用股票型标准去评价债券型基金
- **数字必须带解读**：不能只给"最大回撤 -15.6%"，要加"在同类中属中等水平"
- **投资建议不能空泛**：必须有具体的投资者类型匹配和持有期建议
- **规模风险要提示**：规模 < 1 亿提示清盘风险，规模 > 500 亿提示灵活性受限
- **持有期限制要标注**：有锁定期的基金必须在交易规则和投资建议中明确标注

## 自测用例


| 用例          | 场景              | 预期工具链                                                                               | 核心通过标准                                              |
| ----------- | --------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------- |
| A 股票型完整分析   | 输入一只偏股混合基金代码    | BatchGetFundsDetail, GetBatchFundPerformance, AnalyzeFundRisk, BatchGetFundsHolding | 含 Brinson 归因、行业分布、重仓股分析、四维综合评价；输出 HTML 含 ECharts 图表 |
| B 债券型分析     | 输入一只纯债基金代码      | BatchGetFundsDetail, getBondIndicator                                               | 含久期、信用评级、Campisi 归因、券种配置；不出现重仓股分析                   |
| C 多基金对比     | 输入 3 只基金代码      | BatchGetFundsDetail, GetBatchFundPerformance, GetFundsCorrelation                   | 输出多基金对比 HTML，含收益柱状图、风险雷达图、基金卡片、明细表格                 |
| D 名称模糊搜索    | 输入"易方达蓝筹"       | GuessFundCode, BatchGetFundsDetail                                                  | 先确认基金代码（列出候选），用户选择后再分析                              |
| E 新基金处理     | 输入成立不足 6 个月的基金  | BatchGetFundsDetail, GetBatchFundPerformance                                        | 正确处理数据缺失，不输出近 3 年/5 年排名                             |
| F 货币型精简     | 输入一只货币基金代码      | BatchGetFundsDetail                                                                 | 输出精简报告（7 日年化 + 万份收益），不做行业/持仓分析                      |
| G HTML 渲染验证 | 打开任一 HTML 产出文件  | —                                                                                   | ECharts 图表正常渲染、深浅色切换正常、涨红跌绿配色正确、免责声明存在              |
| H MCP 工具异常  | 模拟部分 MCP 工具调用失败 | 可用工具正常调用                                                                            | 已获取数据正常输出，缺失部分标注原因，不输出空白报告                          |


**失败判定**：无免责声明 / 投资建议空泛 / 数据字段留空 / 类型与分析策略不匹配 / 名称输入未先确认代码 / HTML 图表未渲染

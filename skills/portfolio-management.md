# 投资组合管理技能

当你需要分析或优化投资组合时，遵循以下流程：

持仓存在本地 settings（`upsert_holding` / `get_portfolio`）。行情为公开 HTTP 直连；无现价时仍可管理持仓，可先 `probe_finance_sources`。

## 1. 持仓分析

使用 `analyze_portfolio` 或 `get_portfolio` 工具获取组合整体表现：

### 关键指标解读
- **总市值**：当前持仓的市场价值
- **总成本**：建仓总投入
- **总盈亏**：绝对收益金额
- **收益率**：(总市值-总成本)/总成本 × 100%
- **当日盈亏**：今日变动

### 持仓健康度评估
```
✅ 健康标准：
- 单一持仓占比 < 30%（分散风险）
- 盈利仓位 > 60%（胜率）
- 最大回撤 < 20%（风险控制）
```

## 2. 资产配置分析

### 行业配置
```
- 查看各行业的持仓占比
- 避免过度集中于单一行业
- 建议：单一行业 < 40%
```

### 风格配置
```
- 大盘股 vs 中小盘股
- 价值股 vs 成长股
- 建议：根据市场环境动态调整
```

## 3. 风险管理

### 仓位控制
```
- 总仓位建议：50%-80%（保留现金应对波动）
- 单只个股：不超过总资产的20%
- 加仓策略：分批建仓，降低成本
```

### 止损策略
```
- 固定比例止损：-8% 或 -10%
- 技术止损：跌破重要支撑位
- 时间止损：买入后N天未达预期
```

## 4. 优化建议

### 再平衡
当某项资产占比偏离目标配置超过5%时，进行再平衡：
```
1. 卖出超配的资产
2. 买入低配的资产
3. 恢复目标配置比例
```

### 调仓时机
```
✅ 调仓信号：
- 基本面恶化
- 技术面破位
- 发现更好机会
- 达到止盈/止损位
```


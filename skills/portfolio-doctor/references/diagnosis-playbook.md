# 组合诊断决策引擎

## 一、诊断模式识别与工具选择矩阵

### 1.1 诊断模式识别

收到用户持仓后，按以下优先级识别诊断模式：

| 优先级 | 用户输入关键词 | 诊断模式 | 工具链 |
|--------|-------------|---------|--------|
| P0 | "优化""调整""改进" | 优化建议模式 | 完整诊断 + 配置方案 |
| P1 | "未来""模拟""预测""表现怎么样" | 预测模拟模式 | 完整诊断 + 蒙特卡洛 |
| P2 | "诊断""体检""分析" | 完整诊断模式 | 全维度体检 |
| P3 | "搭配""合理""相关" | 搭配评估模式 | 相关性 + 配置 |
| P4 | 直接给了多只基金+金额（无特定关键词） | 完整诊断模式 | 全维度体检 |
| P5 | 只给了基金代码（无金额无比例） | 搭配评估模式 | 默认等权分析 |

### 1.2 工具选择矩阵

#### 持仓确认阶段

| 场景 | 工具 | 参数 | 说明 |
|------|------|------|------|
| 用户给了基金代码 | `BatchGetFundsDetail` | `fundCodes: ["代码1","代码2",...]` | 批量获取详情，一次最多 20 只 |
| 用户给了基金名称 | `GuessFundCode` | `fundNameOrCode: "名称"` | 逐个匹配代码 |
| 名称匹配不到 | `SearchFunds` | `keyword: "关键词"` | 扩大搜索范围 |

#### 完整诊断工具链（按调用顺序）

| 步骤 | 工具 | 参数说明 | 返回关键字段 |
|------|------|---------|------------|
| 1 | `DiagnoseFundPortfolio` | `fundList: [{fundCode, amount}, ...]` | 三维评分（资产配置/相关性/回测）、诊断结论、雷达图评分 |
| 2 | `GetFundsCorrelation` | `fundList: [{fundCode}, ...]` | 相关系数矩阵、雷达图评分、诊断结论 |
| 3 | `GetFundsBackTest` | `fundList: [{fundCode, amount}, ...]` | 年化收益率、最大回撤、夏普比率、波动率、诊断结论 |
| 4 | `GetAssetAllocation` | `fundList: [{fundCode, amount}, ...]` | 资产大类配置详情、雷达图评分、诊断结论、子账户分析 |
| 5 | `GetFundAssetClassAnalysis` | `holdingList: [{fundCode, amount}, ...]` | 穿透后六大类资产分布（权益/固收/现金/商品/海外权益/海外固收） |
| 6 | `AnalyzePortfolioRisk` | `holdings: [{fundCode, weight}, ...]` | 风险评分、R方、残差方差、标准误差、风险描述 |
| 7 | `BatchGetFundsDetail` | `fundCodes: ["代码1",...]` | 每只基金基本信息（名称/类型/净值/规模/经理/风险等级） |
| 8 | `GetBatchFundPerformance` | `fundCodes: ["代码1",...]` | 每只基金各阶段收益率、同类排名 |
| 9 | `GetPortfolioNavHistory` | `fundList: [{fundCode, amount}, ...]` | 组合净值序列、累计收益曲线数据 |
| 10 | `BatchGetFundNavHistory` | `fundCodes: ["代码1",...]` | 各基金历史净值矩阵（按日对齐） |
| 11 | `GetTxnDayRange` | 无特殊参数 | 可交易日区间，确认回测起止日有效性 |

注意：
- `AnalyzePortfolioRisk` 的 weight 参数是比例（如 0.5 表示 50%），需从金额换算。
- 步骤 9-10 用于生成累计净值曲线和回撤走势图（板块 7A），步骤 11 用于确认交易日有效性。
- 步骤 9-11 失败不阻断交付，但需在报告中标注"净值走势数据获取失败"。

#### 搭配评估工具链

默认仅调用步骤 2（相关性）+ 4（资产配置）+ 5（穿透分布）+ 7（基本信息）。
若用户明确要求输出“组合总评分/健康度评分”，再补调步骤 1（`DiagnoseFundPortfolio`）。

#### 预测模拟工具链

完整诊断 + 额外调用：

| 工具 | 参数说明 | 返回关键字段 |
|------|---------|------------|
| `MonteCarloSimulate` | `weights: {equity, fixedIncome, cash, commodity, overseasEquity, overseasFixedIncome}` | 不同周期的预期收益分布、波动率情景、各百分位收益率、语义化描述、可视化图表 URL |

**weights 参数获取方式**：从 `GetFundAssetClassAnalysis` 返回的六大类资产分布中提取占比，转换为 0-1 的权重值。若穿透数据不足，使用以下默认映射：
- 股票型基金 → equity
- 债券型基金 → fixedIncome
- 货币型基金 → cash
- 商品型基金 → commodity
- QDII 股票型 → overseasEquity
- QDII 债券型 → overseasFixedIncome

#### 优化建议工具链

完整诊断 + 额外调用：

| 工具 | 参数说明 | 返回关键字段 |
|------|---------|------------|
| `GetAssetAllocationPlan` | `expectedAnnualizedReturnRate` / `expectedDrawdown` / `expectedInvestTime` | 资产配置方案 ID、各大类配置比例 |
| `GetCompositeModel` | `assetPlanId: "方案ID"` | 具体基金及配置比例 |

用户风险偏好映射：

| 用户表述 | expectedInvestTime | expectedDrawdown |
|---------|-------------------|-----------------|
| "保守""稳健""低风险" | oneYear | 0.02 |
| "平衡""中等风险" | oneToThree | 0.10 |
| "积极""高收益""能承受波动" | threeToFive | 0.20 |
| 未说明 | 不传，让系统默认 | 不传 |

## 二、数据解读规则

AI 不能只输出原始数据和评分，必须给出**诊断解读**。

### 2.1 相关性解读标准

| 相关系数范围 | 等级 | 解读用语 | 颜色标记 |
|------------|------|---------|---------|
| > 0.8 | 高度相关 | "基金 A 和基金 B 高度相关（相关系数 {r}），持有两者无法有效分散风险，建议替换其一" | 红色 |
| 0.5 - 0.8 | 中度相关 | "基金 A 和基金 B 中度相关（相关系数 {r}），有一定分散效果" | 黄色 |
| 0 - 0.5 | 低相关 | "基金 A 和基金 B 低相关（相关系数 {r}），搭配分散效果良好" | 绿色 |
| < 0 | 负相关 | "基金 A 和基金 B 呈负相关（相关系数 {r}），搭配能有效对冲风险" | 深绿 |

**组合整体相关性评价**：
- 平均相关系数 < 0.3 → "组合分散度优秀"
- 平均相关系数 0.3-0.6 → "组合分散度良好"
- 平均相关系数 0.6-0.8 → "组合分散度一般，建议增加低相关品种"
- 平均相关系数 > 0.8 → "组合高度集中，风险分散效果差"

### 2.2 资产配置评估标准

按穿透后的六大类资产占比评估：

| 资产类别 | 稳健型参考 | 平衡型参考 | 积极型参考 | 失衡预警线 |
|---------|-----------|-----------|-----------|-----------|
| 权益（A 股） | 10-30% | 30-60% | 60-80% | > 90% 或 = 0% |
| 固定收益 | 40-70% | 20-50% | 10-30% | > 90% |
| 现金 | 5-20% | 5-15% | 0-10% | > 30% |
| 商品 | 0-5% | 0-10% | 0-15% | > 20% |
| 海外权益 | 0-10% | 5-20% | 10-30% | > 40% |
| 海外固收 | 0-10% | 0-10% | 0-10% | > 20% |

**配置评价规则**：
- 单一资产占比超过失衡预警线 → 标红提示"XX 资产占比过高（{ratio}%），建议适当分散"
- 完全缺失某类资产 → 提示"当前组合未配置 XX 类资产，可考虑适当配置以分散风险"
- 配置在参考范围内 → 标绿"XX 资产配置合理"

### 2.3 回测指标评价标准

| 指标 | 优秀 | 良好 | 一般 | 偏差 |
|------|------|------|------|------|
| 年化收益率 | > 15% | 8-15% | 3-8% | < 3% |
| 最大回撤 | < 10% | 10-20% | 20-30% | > 30% |
| 夏普比率 | > 1.5 | 0.8-1.5 | 0.3-0.8 | < 0.3 |
| 年化波动率 | < 10% | 10-18% | 18-25% | > 25% |

注意：以上为偏股型组合标准。若组合以债券基金为主，应调整标准：
- 年化收益率：优秀 > 6%，良好 3-6%，一般 1-3%，偏差 < 1%
- 最大回撤：优秀 < 2%，良好 2-5%，一般 5-10%，偏差 > 10%

### 2.4 组合健康度评分规则

综合三个维度各打 1-5 分：

#### 资产配置分散度评分

| 分数 | 条件 |
|------|------|
| 5 分 | 覆盖 4+ 类资产，各类占比均在参考范围内 |
| 4 分 | 覆盖 3 类资产，无失衡预警 |
| 3 分 | 覆盖 2-3 类资产，有 1 项轻微失衡 |
| 2 分 | 仅覆盖 1-2 类资产，有明显失衡 |
| 1 分 | 单一资产占比 > 90% |

#### 相关性分散度评分

| 分数 | 条件 |
|------|------|
| 5 分 | 所有基金对相关系数 < 0.5 |
| 4 分 | 平均相关系数 < 0.5，无高度相关对 |
| 3 分 | 平均相关系数 0.5-0.7，有 1 对高度相关 |
| 2 分 | 平均相关系数 0.7-0.8，有 2+ 对高度相关 |
| 1 分 | 平均相关系数 > 0.8 |

#### 回测表现评分

| 分数 | 条件 |
|------|------|
| 5 分 | 年化收益优秀 + 最大回撤优秀 + 夏普优秀 |
| 4 分 | 三项指标中至少 2 项良好以上 |
| 3 分 | 三项指标中至少 1 项良好以上，无偏差项 |
| 2 分 | 三项指标中有 1 项偏差 |
| 1 分 | 三项指标中有 2+ 项偏差 |

**综合健康度等级**：
- 平均分 ≥ 4.0 → 🟢 健康
- 平均分 3.0-3.9 → 🟡 亚健康
- 平均分 2.0-2.9 → 🟠 需关注
- 平均分 < 2.0 → 🔴 需调整

## 三、优化建议生成规则

诊断发现问题后，必须生成具体可操作的建议。每条建议包含三要素：**问题描述 + 建议动作 + 预期效果**。

### 3.1 相关性问题

| 问题 | 建议动作 | 预期效果 |
|------|---------|---------|
| 基金 A 和基金 B 相关系数 > 0.8 | "建议将 {低收益基金} 替换为与 {保留基金} 低相关的 {建议方向} 类基金" | 降低组合集中度，相关系数预计降至 0.5 以下 |
| 所有基金平均相关系数 > 0.7 | "组合整体高度相关，建议增加不同资产类别（如债券型/QDII/商品型）的基金" | 从根本上提升分散度 |
| 多对基金高度相关 | "持有多只同类型基金（如均为偏股混合），建议精简为 1-2 只同类最优，释放仓位配置其他类型" | 减少冗余，提升配置效率 |

**建议方向映射**：
- 替换偏股型 → 建议方向为"纯债型""偏债混合型"
- 替换债券型 → 建议方向为"偏股混合型""指数型"
- 所有基金都是 A 股权益 → 建议方向为"QDII""商品型"

### 3.2 资产配置问题

| 问题 | 建议动作 | 预期效果 |
|------|---------|---------|
| 权益占比 > 80% | "股票资产占比过高（{ratio}%），建议配置 {20-40}% 的债券类基金" | 降低组合波动率和最大回撤 |
| 权益占比 = 0% | "当前组合无权益资产，长期收益潜力有限，建议配置 {10-30}% 的偏股基金" | 提升长期收益预期 |
| 无固收资产 | "缺少固定收益类资产作为安全垫，建议配置 {20-40}% 的债券基金" | 平滑组合波动 |
| 现金占比 > 30% | "现金占比过高（{ratio}%），长期购买力会被通胀侵蚀，建议将部分现金转为中短债基金" | 提升资金使用效率 |
| 无海外资产 | "当前组合全部配置境内资产，可考虑 5-15% 的 QDII 基金分散地域风险" | 降低单一市场风险 |

### 3.3 回测表现问题

| 问题 | 建议动作 | 预期效果 |
|------|---------|---------|
| 最大回撤 > 30% | "组合最大回撤较大（{dd}%），建议增加低波动品种（纯债/货币）降低整体回撤" | 预期最大回撤降低 5-10 个百分点 |
| 夏普比率 < 0.3 | "风险调整后收益较低（夏普 {sharpe}），建议优化持仓结构，淘汰低夏普基金" | 提升组合风险收益比 |
| 年化收益 < 同期存款利率 | "组合长期收益低于无风险利率，承担了风险但未获得相应回报，建议重新审视持仓" | 提升收益水平至合理范围 |

### 3.4 持仓数量问题

| 问题 | 建议动作 | 预期效果 |
|------|---------|---------|
| 持有基金 < 3 只 | "持仓数量较少，分散度不足，建议增加至 3-5 只不同类型基金" | 提升分散效果 |
| 持有基金 > 10 只 | "持仓数量过多，管理难度大且边际分散效果递减，建议精简至 5-8 只核心持仓" | 降低管理复杂度 |
| 单只基金占比 > 50% | "单只基金占比过高（{ratio}%），若该基金表现不佳将严重拖累组合，建议降低至 30% 以下" | 降低单一基金风险 |

### 3.5 优化建议生成流程

1. 收集所有诊断发现的问题
2. 按严重程度排序（单一资产 > 90% → 相关系数 > 0.8 → 回撤 > 30% → 其他）
3. 每个问题生成一条建议（三要素齐全）
4. 若用户提供了风险偏好，额外调用 `GetAssetAllocationPlan` 给出配置方案
5. 仅在用户明确要求“可落地候选基金”时，用 `GetCompositeModel` 将配置方案落地到具体基金候选
6. 总结为"最重要的 3 条优化建议"放在报告显眼位置

## 四、错误处理与边界场景

### 4.1 持仓解析失败

| 场景 | 处理方式 |
|------|---------|
| 无法解析输入格式 | 提示"未能识别持仓格式"，给出支持格式示例 |
| 基金代码不存在 | 标注该基金"未找到"，提示检查代码，其余基金继续分析 |
| 名称匹配多个结果 | 列出候选列表让用户选择，选择后继续 |
| 只输入了 1 只基金 | 提示"组合诊断至少需要 2 只基金"，引导至基金分析专家 |

### 4.2 数据缺失处理

| 场景 | 处理方式 |
|------|---------|
| 部分基金数据缺失 | 标注"数据暂未披露"，用已有数据出报告 |
| 基金已清盘 | 标注"已清盘"，建议替换为同类在售基金 |
| 相关性数据不足（基金成立时间短） | 标注"部分基金成立时间较短，相关性数据可能不够准确" |
| 回测期限不足 | 按实际可回测期限输出，标注"回测期限不足 1 年，结果仅供参考" |

### 4.3 工具调用异常

| 场景 | 处理方式 |
|------|---------|
| DiagnoseFundPortfolio 失败 | 这是核心工具，重试一次；仍失败则用其他已成功返回的工具数据构建可用维度的评分（缺失维度标注"数据暂不可用"，严禁估算） |
| 单个辅助工具失败 | 跳过该工具，标注"XX 数据获取失败"，用已有数据出报告 |
| 多个工具连续失败 | 输出已获取的基本信息，标注"部分数据源暂时不可用" |
| 持仓超过 20 只 | 分批调用批量接口（每批 ≤ 20），合并结果 |
| MonteCarloSimulate 权重无法提取 | 跳过模拟，标注"资产穿透数据不足，无法进行蒙特卡洛模拟" |

### 4.4 特殊场景

| 场景 | 处理方式 |
|------|---------|
| 所有基金都是同一类型 | 正常分析，但在诊断结论中强调"组合全部为 XX 类基金，建议增加其他资产类别" |
| 用户给的金额不一致（如有的万元有的元） | 统一单位后确认，避免误判 |
| 用户持仓含货币基金 | 货币基金在资产配置中归入"现金"类，相关性分析中可排除（与其他类型相关性极低） |
| 用户要求对比两种不同组合方案 | 分别诊断两个组合，最后对比输出关键指标差异 |

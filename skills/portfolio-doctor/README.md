# Portfolio Doctor（组合诊断师）

基于盈米MCP 插件的 AI 组合诊断技能。用户输入基金持仓（代码+金额），输出一份完整的组合"体检报告"，含资产配置分析、相关性评估、历史回测和可操作的优化建议。

## 能做什么

- **组合健康度诊断**：三维评分（资产配置 / 相关性分散 / 回测表现），一眼看出组合短板
- **资产配置分析**：穿透基金看底层资产大类分布（股/债/现金/商品/海外），评估配置合理性
- **相关性评估**：基金间相关系数热力图，发现风险集中（高相关）和分散良好（低相关）的组合
- **历史回测**：年化收益、最大回撤、夏普比率、波动率，评估组合实际表现
- **蒙特卡洛模拟**：基于资产配置权重，模拟未来收益概率分布
- **优化建议**：针对发现的问题给出具体可操作的调整方案

## 快速启动

### 方式一：完整组合诊断（→ 模板一 HTML，含三维雷达 + 资产饼图 + 相关性热力图 + 净值曲线）

```
帮我诊断持仓：005827 5万、110011 3万、003834 2万，生成 HTML 诊断报告：要有三维健康度雷达图、资产配置穿透饼图、基金相关性热力图、历史净值走势和回撤曲线，最后给优化建议表
```

### 方式二：优化建议（→ 模板三 HTML，含优化前后对比表 + 调仓方案）

```
帮我优化组合：易方达蓝筹 5万、景顺长城新兴成长 3万、华安物联网 2万，生成 HTML 报告展示优化前后的配置评分、相关性评分、预期回撤和夏普比率对比，附上具体调仓方案
```

### 方式三：模拟预测（→ 模板一 HTML + 蒙特卡洛模拟板块）

```
我持有 005827 50%、110011 30%、003834 20%，总共 10 万，帮我做一个未来 3 年的蒙特卡洛模拟，生成 HTML 报告展示乐观/中性/悲观三种情景的收益概率分布图
```

### 方式四：风险偏好适配（→ 模板一 HTML + 风险适配板块）

```
我能承受 20% 的最大回撤，投资期限 3 年，帮我诊断一下 005827 5万、110011 3万 这个组合跟我的风险偏好匹不匹配，生成 HTML 报告
```

## 文件结构

## 独立运行

- 本目录业务素材自包含，上传到 Coze 时无需额外业务依赖。
- HTML 报告的完整视觉参考（内联 CSS/JS）由同仓库 `../yingmi-skill/references/demo-report.html` 统一维护，生成 HTML 前必须读取该文件。

## 依赖

- **盈米MCP 插件**：提供组合诊断、相关性分析、回测、资产配置、蒙特卡洛模拟等 API 工具
